# P34 定向验证合同

仅检查 Corridor01 GT 参考点、初始化调用链、地图归一化与时间对应。
不修改运行源码、标定、地图或原始数据，不运行定位回放，不做 ICP。

1. 实际完整回读已解码 bag，核对2777扫描、79932911点、55957 IMU和6720图像；
   每个有序XYZ/time与冻结解码缓存比对，IMU/图像payload与原bag重新比对，并重算文件SHA。
2. 重读官方GT ZIP并与本地GT逐行数值比较，不依赖旧报告的PASS标签。
3. 检查首个完整IMU覆盖扫描。若早于GT支持，不外推；几何诊断明确改用首个同时
   满足IMU覆盖和GT支持的扫描，记录这个必要的时间限制。
4. 固定同一扫描、同一预处理、同一完整归一化目标地图，不按GT误差选择帧或区域。
   复用生产0.5–80m筛选、0.25m source voxel、1400点上限；target按生产两次0.15m
   voxel。源为raw扫描的共同预处理，不伪称历史在线NDT Source，也不恢复旧OOSM历史。
5. H1=GT为LiDAR；H2=GT为IMU，右乘已经冻结的proper RC2 T_I_L。
   二者均明确条件于“GT world=原始PCD XYZ世界”，再左乘已知地图归一化矩阵。
   该世界系同一性不是既成事实。H3缺少独立Body外参、H4缺少已认证T_M_W，均不伪造矩阵。
6. 只对H1/H2各做一次初始NN检查，报告median/P90和0.5/2/8m覆盖率。
   单扫描几何不能认证GT参考点；不把较低NN自动当作正确假设。
7. 官方评测要求支持IMU解释，但原始GT导出参考点未独立认证。若H2的参考点证据、
   proper外参、同刻支持和有限点云合同均成立，最多对预先选定的H2做一次
   原生NDT诊断（0.8/0.08/0.001/40），不按NN结果换候选，不回写状态。即使收敛也不认证
   世界系假设。若参考点证据不足或矩阵/输入非法，则不执行NDT，说明阻塞。
8. 不解释 # s 67 为已证明的当前bag+67s；只给出可证实的时间与源码行为。

所有候选/阈值在几何计算前固定。原始官方LiDAR-IMU旋转若非proper，单独报告；
不把它强当刚体。本轮不改标定，H2只复用现有runtime proper外参并记录其与原数值的关系。
矩阵合法性容差：SO(3) Frobenius误差和det偏差≤1e-5；GT四元数正规化后构造旋转。
原始/归一化地图对应点检查容差预设5e-5m，考虑原normalizer的float运算。

执行前准入决定：参考点及T_M_W均未认证，故本轮使用 `--NN-only`，完整NDT调用预算
实际为0；不根据NN结果改变此决定。H1/H2仅是明确标记世界系同一性条件的几何诊断，
不是已经合法成立的运行初始化。
