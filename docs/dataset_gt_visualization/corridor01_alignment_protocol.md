# Corridor01 GT 地图显示修复：离线估计协议

用户授权：2026-10-15，修复 GT/地图显示后打开 RViz。不修改任何定位算法、
原始地图、GT、标定或冻结评价。不是非 GT 初始化，也不生成定位精度成绩。

只估计一个固定 proper SE(3) `T_normalizedMap_GTWorld`，不允许缩放、镜像、
逐段变换或按时间修改 GT。GT 传感器为已核实 lineage 的 IMU，使用现有 RC2
proper 外参 `T_IMU_LiDAR`。目标为 SHA256=103a01b2… 的现有归一化地图。

先固定扫描：相对 GT 首时刻，拟合 20/80/150/220 秒；验证 10/60/120/180/240 秒。
每个目标只取最近 header，误差不得超过60ms。不按误差重新选帧。XYZ 为真实
decoded raw 点，固定0.5–80m范围，无 GT 逐点去畸变；GT 仅在 header 内插。

复用已安装 Open3D 0.19 成熟实现：1m 体素，FPFH；一次固定种子7 RANSAC，
上限100000次、1.5m对应距离；随后0.5m/0.2m两尺度点到面ICP，分别1.5m/0.6m
对应距离，每尺度最多100次。没有完整NDT调用，没有算法参数调节。

每个独立验证扫描均须：NN median≤1m、P90≤3m、0.5m覆盖≥50%、2m覆盖≥80%。
门槛仅决定是否可以作为有几何支持的显示估计，不能认证官方坐标含义或定位精度。
不满足则不把结果设置为已正确对齐，不扩大扫描/参数搜索。

旧前缀评价模式保留。若通过，新增独立显示配置和入口，使用固定估计变换并明确
标记 ESTIMATED / GT_ASSISTED / DISPLAY_ONLY，验证代码和点云缓存保留。
