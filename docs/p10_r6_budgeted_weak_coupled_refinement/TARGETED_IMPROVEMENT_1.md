# 唯一针对性修改：保留未过期的局部惯性参考

V0 三个完整 4127 帧回放已经冻结；本修改属于本轮允许的唯一开发改进，
不是独立验证，也不追溯修改 V0/R5。
V0 post-hoc GT 已经看过；V1 是知情开发修改，不声称新的 label-blind 或独立
confirmatory 实验。V1 运行进程不读取 GT，修改理由和策略不使用逐帧 GT 标签。

非 GT 原因：V0 Coupled 有 768 个事件，但仅 116 个具有有效锚点；
106 次有界局部反馈采用了 R5 非局部 Pending 的消费策略，立即删除锚点。
652 个触发帧因为锚点缺失未尝试修正。Weak-only 同样为 676/780。

唯一修改：R6 局部模式在成功状态更新后，不因有界局部反馈消费已有锚点。
原点、原点时间戳、传播参考均不替换为当前修正位姿；仍按因果 IMU 区间
传播。原 2 秒生命周期、0.25 秒间隔护栏、过期当帧不得重建、只在普通稳定
帧新建等合同均不变。R5 settleCoupledAnchor 的代码和调用不改，非局部消费
策略保留。失败滤波状态仍立即停止。

弱/强模型、rho、score 质量带、步长、事件阈值、完整 NDT 参数和 2 jet/3 value/
0 extra align 预算全部不改。不使用 GT 决定哪个帧保留锚点。

风险：短时惯性参考不是绝对真值；其传播仍依赖当前因果滤波速度/偏置，
不能声称与滤波完全独立。保留锚点可能造成连续错误修正，需要全段比较，
但不得按 GT 选择回滚或重跑。最多一次 attempt_1 三模式完整实验，随后停止。

验收自检：局部反馈后原点/时间戳/预测不变；下一帧因果传播正确；生命周期
不延长；触发帧不能重建；原 R5 消费行为不变。评价器在 GT 前验证实际日志。
