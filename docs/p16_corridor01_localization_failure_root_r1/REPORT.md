## 3. 为什么“收敛”并不能排除失败

两个分支均396/396报告优化器收敛、396/396 OOSM应用。Control在B窗口：

- 40/40扫描只迭代1次；raw相对初值平移变化中位数13.7899mm。
- 32/40同时满足raw相对漂移>1m、fitness<0.05m²。
- fitness中位数0.01583772m²。0.05仅为本轮离线描述性分组，不是新准入门槛。
- 主窗口289/316只迭代1次，47帧同时满足上述低fitness/大误差条件。

真实源码事实：

1. `getFitnessScore()`是平均最近邻距离平方(m²)，不是PCL NDT原生
   likelihood目标，不能直接拿它代替地图位置正确性。
2. 当前节点以`hasConverged()`进入发布分支，记录fitness但没有独立位置
   正确性证书。
3. 本机PCL 1.10.0的NDT退出条件可由小平移步或最大迭代等触发。
   本配置epsilon=0.001；其中退出分支比较translation_sqr与epsilon，
   该分支对应31.6228mm，不是1mm。rotation epsilon默认0且此节点未设。
   同一epsilon也用于线搜索，不能把上述单位解释直接变成参数修复。
   现有日志没有终止原因/梯度，不能证明1次迭代是错误收敛或唯一根因。

**能够证明的是：该收敛标志和低fitness不足以识别这些位置偏差。**
尚不能证明每个案例是错误盆地、缺失地图、点云畸变还是曲率退化。

## 4. Step limit不是初始漂移的主要来源

Control全段28帧限幅（平移3、旋转28，存在重合）；首个平移限幅在
TX362，+31.408266s，晚于0.5m和1m持续漂移起点。
主窗口raw RMSE=1.859315m，used=1.857614m，差约1.70mm；
单帧平移限幅最大变化0.438875m（TX367）。它会影响后段，但不能解释
早期已存在的raw偏差。

Weak-only raw→used包含“候选替换+限幅”，不能全部算为限幅收益。
本轮分别保留raw、used_before_step_limit及final_used。

## 6. 确认的反馈敏感性

### NDT内部预测

`handleCloudLocked()`的平移初值来自：

```
initial_guess = previous_pose_ * delta_pose_;
delta_pose_ = previous_before.inverse() * current_used;
```

它不是EKF平移预测；IMU局部先验只替换初值旋转。系统整体仍包含真实
IMU传播、EKF校正和固定延迟OOSM。本轮没有运行新的gyro/CV简化链。

因此用于下一帧平移的实际公式为：

```
p_guess_next = p_used_k + R_used_k R_used_(k-1)^T (p_used_k-p_used_(k-1))
```

从CSV重建下一初值，Control/Weak最大差分别5.032e-8/5.546e-8m，
来自PCL float旋转到归一化四元数的表示差，未修改历史回放容差。
九次修正对下一帧初值的同历史代数影响为8.8878–16.5462cm，平均13.0059cm。

### EKF外部观测路径

`processNdtObservationLocked()`先按固定比例/cap直接校正位姿，再执行：

```
v_ndt = (p_target_k-p_target_previous)/dt;
v_ = .4*v_ + .6*v_ndt;
```

这条外部NDT路径不是依据观测协方差计算的标准Kalman位姿增益。
`NDT_CORRECTION_APPLIED`日志写在速度混合之前，不能将其速度当作混合后
观测值。本轮根据冻结配置与上一测量重建，而非假称日志直接记录了它。

同历史、过去测量及混合前速度固定，实际候选替换的直接影响严格为：

```
delta_v = .6 * (p_feedback_IMU-p_same_history_nominal_IMU) / dt;
```

九次对应0.2622–0.4978m/s，平均0.3898m/s。这是已实现公式的代数
敏感性，不是反事实完整轨迹，也不证明该速度变化一定错误。

## 7. 推荐下一阶段：配准修正与物理运动记账分离

最多保留两个问题，优先级如下：

1. **首选：配准修正进入运动预测/速度观测的双通道。** 用小范围实验
   区分物理运动与位置修正，避免未经验证地把修正差分当运动增量。
   对`p_measure=p_motion+c`，速度差分含`(c_k-c_(k-1))/dt`；固定旋转
   近似下下一NDT初值含`2c_k-c_(k-1)`。存在完整旋转/外参时必须做正确
   运输，不能把近似式直接塞入生产路径。成熟误差状态滤波的观测/运动
   分离应优先复用；这是待验证的具体缺口，尚不是已证明原创创新。
2. 次选：收敛标志/停止尺度与位置可靠性不一致。属于成熟优化器语义
   和工程可靠性问题，不把Hessian检测或更严格阈值本身称为创新。

建议下轮只冻结问题1。拟修改位置：

- `dog_prior_map_ndt_node.cpp::handleCloudLocked()`：previous_pose_/delta_pose_
  初值记账及其与时间对齐惯性运动的区分；不修改NDT目标函数。
- `fusion/ndt_observation.cpp::processNdtObservationLocked()`：外部NDT
  有限差分速度的输入记账；复用既有传播/校正，不扩展滤波器状态。
- 最小诊断：直接记录速度混合前/后、此次配准位置创新、回放终点校正
  前/后状态。仅开启实验标志，默认生产路径不变。

最少验证：先做同历史单步代数/时间测试，再固定原40秒输入运行一次
新Control和一次新Weak-only，与已有对应分支比较；不做参数网格。
至少将诊断与行为修复分开，不能同时调优化器停止参数制造改善。
额外在线计算预计O(1)小规模向量/SE(3)运算；无新增配准/地图。具体ms
及长期收益未测量，须下轮验证。

唯一NEXT：`TEST_REGISTRATION_CORRECTION_MOTION_SEPARATION`，待科研总控冻结合同。

## 8. 已证明与仍未证明

已证明：raw及预测初值存在偏差；收敛+低fitness不能排除位置错误；
step limit并非早期偏差起因；修正实际影响位姿、速度混合和下一初值；
Weak-only完整因果轨迹在冻结评价下优于Control，但没有消除晚期漂移。

未证明：唯一几何退化根因；单个事件独自造成全部长期收益；速度混合
独自解释TX115回放放大；新机制必然改进精度或具备原创性。

若要把TX115后续增幅唯一分配给速度/旋转传播，最小缺口是该事件直接
记录的**混合后、回放前状态及release时刻校正前状态**。现有日志不含
完整中间状态；本轮不扩大取证、不补造该状态或再运行定位。
