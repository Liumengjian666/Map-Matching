## 平方根实现及数学边界

默认关闭开关：`filter/experimental_square_root_covariance_enable`。
实验分支以正对角下三角S为唯一权威协方差存储，P=S S^T。
`FilterStateSnapshot`携带S和模式标签；其旧P字段在新模式明确清零，
并非零协方差，也不是有效缓存。需要完整协方差时调用`covarianceView()`。
恢复时复制S，拒绝标签不匹配；不对派生double P做重新分解。
当前传播和保存历史均无需形成完整P。15维误差状态和名义状态数学不变。

1. IMU：A=[F S,L_Q]，A^T=Q_orth R，S_new=R^T，规范化对角符号。
   L_Q直接按已有对角过程噪声构造，零噪声方向保持零，不加jitter。
   因果部分区间原有局部变化Q以两个秩一列精确表示，保留位置/速度交叉项。
2. SKF：C=(H S)(H S)^T，K=S(H S)^T C^-1，保留原相对残差与CI公式。
   使用[(I-KH)S,K L_CI]的QR实施原Joseph/条件正项和。
   历史参考状态的投影不确定性来自J S_ref的Gram，不忽略其不确定性。
3. NDT：S_new=D S，D由原0.85缩减及1e-4/1e-5方差下界确定。
   SKF ON/OFF共用这一平方根DPD路径。
4. OOSM：保存、回滚、恢复、SKF/NDT重放以及因果端点查询都携带S。
   不修改调度、固定滞后或IMU输入选择，不新增状态维度或窗口优化。

运行时使用double QR和小维求解，不无条件采用扩展精度。
80位计算仅用于结束后的5个稀疏因子检查。没有截断负特征值或增大噪声。
完整double P视图在极高条件数下一般仍可能损失小特征值；它没有写回权威存储。
本次5份派生视图的高精度特征值也为正，不能据此保证所有未来dense view。
