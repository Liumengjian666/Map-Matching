## 实际测量与数学

389幅合法因果图像，7幅超过原50ms年龄门槛跳过。真实原图经MEI标定
矫正到透视相机，FAST/KLT及RANSAC生成10054条候选闭合轨迹、45545个像素
观测。这些不是全部通过三角化的滤波观测。图像/特征时间采用uint64 ns。

相机点 `q = R_icᵀ[Rᵀ(P−p)−t_ic]`，残差 `r=z−π(q)`。
预测Jacobian为 `H_p=−Jπ R_icᵀ Rᵀ`、
`H_θ=Jπ R_icᵀ skew(Rᵀ(P−p))`、`H_f=Jπ R_icᵀ Rᵀ`；
θ为右/body姿态误差。用实时残差和FEJ位姿Jacobian，特征三角化后做
左零空间投影消除三维特征状态，固定1px像素噪声，95%逐特征chi-square筛选，
最多40条接受特征/事务，然后正交压缩。

最多11个6维克隆；核心仍15维。联合平方根保存完整交叉协方差。
准确克隆增广 `L_aug=[L; J_pose L]`，初始奇异克隆协方差合法，无jitter。
每个真实IMU区间持有同一个6维加计/陀螺噪声驱动，图像子区间与剩余区间
共享同一噪声/相关性；真实尾时刻只边缘化驱动，bias随机游走使用独立增量。
OOSM保存/恢复联合因子、克隆、FEJ、真实head输入和driver身份/活动状态。
图像虚拟节点不会替换真实IMU输入。NDT DPD只缩放联合因子的原核心行。

DCReg必须来自已接收且完整scan_end≤image的报告，方向判据不变，
只选真实视觉Jacobian有信息交集的弱方向。使用受约束增益和平方根Joseph：
`L_new=QR([(I−KH)L, K R_visual^1/2])`，右注入并reset核心/克隆姿态。
这是选择性增益适配，不是原SKF全信息投影算法的完整复现。
本数据实际只更新旋转弱方向，直接位置修正量均为0。

用户明确批准A/B共用新的因果head/ZOH时序、右误差F/G及共享子区间噪声
接口。它们不同于历史完整midpoint路径，不属于A/B干预变量。
原初始化、IMU噪声数字、NDT/DCReg/Multi-NDT、OOSM lag、velocity_blend=.6
未改。历史NDT位姿/协方差处理仍有启发式部分，完整统计一致性未证明。
