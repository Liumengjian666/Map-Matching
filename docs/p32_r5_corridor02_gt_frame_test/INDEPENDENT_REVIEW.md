## 处置及停止

无新的实质指控需要修改实际NN程序；没有重跑准备/NN、改变阈值或追加候选。
保留负结果和GT原点无法辨识的限制；复核通过不等于六个假设几何通过，
更不等于官方坐标语义、非GT初始化或成熟融合精度已经通过。

code-review-and-quality作提交前质量检查；doubt-driven-development促成上述只读复核、
单次用户确认及明确的停止边界，没有引入额外科研实验。
