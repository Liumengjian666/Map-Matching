# P33 固定合同

只分析坐标/时间关系，不修改运行源码、YAML、标定、地图或原始数据。
复用P34完整输入校验证据，本轮再从实际解码bag抽取并对照3帧，不重复全量解码。

- 以原始首个LiDAR header为相对零点，预定+67、+100、+150秒；从完整整数ns索引
  选择唯一最近扫描，遇到等距取较早者。三帧选择在NN之前冻结，不按几何结果换帧。
- 用同一时刻GT平移线性、四元数SLERP插值，禁止外推；不使用GT逐点去畸变。
- 对每帧只检验A=`GT=T_G_L,G=M`，B=`GT=T_G_I,G=M`。
  B复用既有runtime proper `T_I_L`，同时保留官方原始非正交矩阵的合法性限制。
- 不在缺少官方读取/乘法代码时为`world_darpa`指定方向，因此不新增其候选投影。
- 复用P34 `geometry_probe.cpp`及已编译、哈希校验过的工具，以`--NN-only`对同一
  官方原始PCD XYZ做共同预处理：source .25m/cap1400、target两次.15m。
  三帧共6次固定NN查询，ICP/NDT align/定位回放预算均为0。
- PCD VIEWPOINT仅作为元数据单独记录，不加入任何变换。
- 用实际原始Bag record及header核对`rosbag play -s 67`；不从double推算ns。
  同时记录重打包后record已改为sensor/scan_end的区别。
- YAML只比较其完整数值矩阵与本轮选定+67附近GT（A/B）；不求额外拟合变换，
  不把数值接近视为已经认证其语义或时间。
- 记录三帧点级投影空间分布与图示。NN好坏不是唯一语义证明；缺图、raw运动畸变、
  未认证的导出坐标链作为限制报告。关键官方实现缺失时停止，不扩展搜索。

坐标符号严格采用用户的M/G/W/D/L/I/B/O；归一化在线地图记O，避免再用W泛指所有世界。
参考点/世界同一性未闭合时输出UNCONFIRMED，不造单位阵来补未知外参。
