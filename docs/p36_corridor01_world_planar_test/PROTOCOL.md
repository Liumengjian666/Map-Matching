# P36 冻结合同（先于本轮 NN 结果）

只检验官方生效 YAML 数值矩阵 Y 的两种左乘方向。P 仅表示本次数值假设中的
官方原始 PCD XYZ 坐标系；Planar=DARPA、GT=T_W_L、Y 的物理方向均未认证。
不将名称相似或几何匹配当成官方语义证明。

固定复用 P33 三帧，不重新选择时间：

| 原始帧 | scan header (uint64 ns) | 原始首 LiDAR 后秒 |

- A：`T_P_L = Y @ GT`，假设 Y=T_P_W。
- B：`T_P_L = inverse(Y) @ GT`，假设 Y=T_W_P。
- C0：P33 已冻结的 `GT` 结果。
- C1：P33 已冻结的 `GT @ T_I_L` 结果；其外参是既有 runtime proper 矩阵，
  不把它改称为已经认证的 GT 参考点。
- Y 从真实 OpenCV YAML 读取，检查有限性、齐次行、旋转正交性和行列式，
  容差沿用探针的 1e-5。保留文件的六位小数，不正交化、不拟合。
  B 用完整数值矩阵逆，不将四舍五入后的旋转转置冒充精确逆。
- 从真实完整解码 bag 重读且仅重读冻结的三条点云；核对完整整数 header、
  record=scan_end、frame_id、XYZ 顺序/字节 SHA、标准缓存 XYZ/time 转换。
- GT 复用 P33 原解析器：整数纳秒、平移线性、xyzw SLERP、禁止外推；
  与 P33 插值矩阵和上下界逐项核对。不调整 GT 时间，不用 GT 逐点去畸变。
- 原始地图、预处理、最近邻与 P33 完全一致：range 0.5–80m，source voxel
  0.25m/cap1400，target 连续两次 0.15m；PCL KdTree；median 取排序的 N/2，
  P90 取 floor(0.9*(N-1))，coverage 使用 <=。PCD VIEWPOINT 不参与变换。
- 复用哈希相同的 P34 探针，仅 `--NN-only`。程序的 H1/H2 是旧槽位名称；
  本轮明确映射到 A/B，两组均假设 GT 为 LiDAR，不添加 LiDAR–IMU 外参。
- 新增三帧 × 两方向 = 6 次固定 NN 统计；C0/C1 只导入历史结果，不重跑。
  ICP=0，NDT align=0，定位回放=0，不搜索其他矩阵。
- 每帧预处理结果与 P33 缓存逐字节相同才接受比较。图像只是原坐标投影，
  不做图像对齐、平移、旋转或根据结果选点。
- 判读同时报告残差和覆盖率及三帧一致性；不以相对改善百分比独自宣布几何
  重合。NN 不是定位误差，几何支持不是正式精度或非 Oracle 初始化认证。

本轮小文件 SHA 新计算；大型 bag/cache 完整 SHA 明确继承 P34 完整验证，
本轮核对大小和实际三帧内容，不宣称重新全量校验大型输入。
