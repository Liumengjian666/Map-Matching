## 4. 判断

1. A 对三帧的 NN 距离都有大幅数值改善，median 相对 C0 降低约 87.74%、87.68%、
   88.56%。这是本轮支持“Y 的某个方向包含有用坐标关系”的线索，不应抹掉。
2. 但 A 仍有 13–20m median，全部 0.5m/2m 重合为零；三帧均没有有效三维重合。
   XY 看起来接近走廊结构，而 XZ 显示明显高度偏离。仅平面视觉接近不能验收 3D 初始化。
   不将此图像观察当成已经定位了唯一俯仰／高度错误来源。
3. B 与 C0/C1 一样仍为近百米至百米级残差，没有解决问题。
4. 三帧一致支持“当前 Y 的两种直接左乘链均不足以解决完整关系”。
   本轮不能认证 GT 是 LiDAR/IMU/Body，不能证明地图版本或世界定义出错，
   不能由有序点云刚体投影排除所有 raw 运动畸变／地图覆盖限制。
5. 没有得到可认证的 `T_P_L`，不把 GT 或本轮候选写入运行初始化；不修改运行源码。
