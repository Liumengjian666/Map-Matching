## 2. Y的用途和合法性

官方[SuperLoc发布页](https://superodometry.com/superloc.html)确实明确提供初始化位姿文件，
用于支持可配置初值的定位模块。因此初始化用途有官方直接依据。

但所查固定版本[官方定位说明](https://github.com/superxslam/SuperOdom/blob/f10e65cd50007767b22e4c401689665e20d827d6/doc/LOCALIZATION.md)
和本地对应源码使用 `start_pose.txt` 或xyz/rpy参数，没有找到这两个YAML字段的读取器，
不据此认证Y等于哪一时刻的 `T_map_lidar`。证据范围及行号见 `matrix_interpretation.md`。

```text
Y =
[ 0.135990 -0.990409 -0.024406  1.968147
  0.990705  0.136027  0.000140 -6.879292
  0.003181 -0.024198  0.999702 -0.896125
  0         0         0         1        ]
```

有限、齐次行正确；`||RᵀR−I||_F=1.2379704056665196e-6`，det=`0.999999216169924`。
在既有1e-5容差内是近似刚体矩阵，但不把舍入数值说成精确正交。保留原数值；
反向用完整数值逆，没有拟合、轴旋转、附加平移、GT乘法或猜测DARPA=IMU/Body。
原文件没有明示平移单位；本轮按地图XYZ的米尺度解释，这是实验约定。

## 3. 唯一单帧、两种直接放置

`p_A=T_A_B*p_B`。

- A：假设 `Y=T_M_L(t0)`，只执行 `p_M=Y*p_L`。
- B：假设 `Y=T_L_M(t0)`，只执行 `p_M=inverse(Y)*p_L`。

共同输入：原始官方PCD，未归一化、不用VIEWPOINT；range .5–80m、source voxel .25m/
cap1400；target连续两次.15m后225826点；相同P34探针和PCL KdTree。raw扫描按
header时刻刚体放置，没有GT逐点补偿。统计索引与P33/P36完全相同。

|---|---:|---:|---:|---:|---:|
| A：Y | 0.906276405 | 4.076959133 | 35.714286% | 71.285714% | 99.000000% |
| B：Y⁻¹ | 3.406847477 | 6.159274578 | 12.571429% | 37.500000% | 98.928571% |

### NDT准入与结果边界

本轮执行端在结果产生前采用既有初始化验收尺度作**额外保守准入**：
median<=1m、P90<=3m、0.5m overlap>=50%，并需图示结构合理。
这不是用户指定的数值阈值，也不是PCL求解器能力边界。

A通过median，但P90=4.077m、0.5m overlap=35.71%，未通过全部冻结条件；B也未通过。
本轮没有在看到结果后放宽门槛，因此 **NDT=0、ICP=0、定位回放=0**。
不能把未通过这一保守门槛外推成“Y不能作为较粗的NDT初值”。
`geometry_gate.json` 的false明确只对应这一预注册严格门槛，不是否定所有粗几何支持。

XY/XZ/YZ图 `initial_pose_projection.png` 使用同一原始地图、同一Source及两候选。
各轴对应固定范围，全部面板跨度相同343.637950516m、等比例，无候选专属缩放。
实际检查图像：A位于地图近原点南向走廊附近，B落在反向北侧结构附近；
A较好但仍存在偏移/局部结构对应不确定性。单帧重复结构无法据此认证全局位置唯一。
保留离线图，不开发或启动RViz功能，也不运行完整定位。
