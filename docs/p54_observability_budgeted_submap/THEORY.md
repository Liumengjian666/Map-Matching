# P54 几何信息感知预算子地图：数学合同

本轮只研究离线 Tile 子集选择；不修改生产定位路径。

## 输入与候选集合

每帧候选 Tile 严格限于 P46 该帧实际激活的 P45 Tile ID。预测位姿为冻结 P46 `initial_guess`，Source 为 P47 已冻结的 1400 点 Source。每个候选 Tile 的成本是其原始 P45 目标点数；不重新降采样、不改变 Tile 尺寸或坐标。

两个点数上限为 1,200,000 与 1,500,000。若完整 P46 Local Target 已低于上限，两种方法均保留完整 Target。超过上限时，只能在活动 Tile 集合内做确定性贪心选择。

## 预测几何覆盖

将 Source 用冻结预测变换到地图系。离线 Tile 描述符由 P45 Target 按 0.8 m 全局对齐体素聚合：任一含至少 3 点的体素贡献占据质心；含至少 6 点且协方差可分解的体素另贡献平面描述符。

预选择阶段的便宜覆盖代理是：预测 Source 点到所选 Tile 占据质心的最近距离不超过 2 m。该阈值固定采用既有 P46 几何诊断的 2 m overlap 口径，不读取 NDT 结果或 GT。选完后再用所选实际 P45 点云建立 KD-tree，计算精确点到点 2 m 覆盖率。只有精确覆盖率达到 95% 才执行 NDT；不达标的候选保留为 `COVERAGE_INFEASIBLE_EXACT_NO_ALIGN`，不重选、不对不完整 Target 输出定位结果。

该覆盖定义是预测位姿下的地图支撑安全门，不是 NDT 内部实际使用点数。PCL NDT 不暴露本实验需要的逐 Source 有效匹配计数，报告中将精确 2 m 支撑点数明确标为 proxy。

## 半正定几何信息近似

对每个描述体素的点坐标协方差求特征分解，最小特征向量为候选平面法向 `n`。平面权重固定为

`w = clamp(1 - lambda_0 / lambda_1, 0, 1)`

其中 `lambda_0 <= lambda_1 <= lambda_2`，且 `lambda_1 > 1e-6 m^2`；不满足条件的体素只参与占据覆盖，不参与信息计算。该权重抑制线状/各向同性单元，但它不是传感器噪声模型。

对预测 Source 点 `p_L`，以 P46 预测旋转 `R_0` 得到相对 LiDAR 原点的地图向量 `r = R_0 p_L`。在 P47 固定 chart `p = p_0 + 0.8 m * eta_t`、`R = Exp(eta_r) R_0` 中，点到局部平面的线性行取为

`J = [0.8 n^T, (r x n)^T]`。

每个 Source 点至多使用所选 Tile 中最近且距离不超过 2 m 的一个平面描述符。几何信息代理为

`H_geo = (1 / N_source) * sum_i w_i J_i^T J_i`。

因此 `H_geo` 由加权外积构成，数值上应为半正定；坐标是 P47 的无量纲六维局部 chart（平移基准尺度 0.8 m、旋转单位 rad），不是原始米/弧度混合 Hessian，也不是概率 Fisher 信息矩阵。若 PSD 数值检查失败则该帧信息分数无效，不能静默裁剪负特征值后继续。

弱方向量为 `lambda_min(H_geo)`；六维总体信息用固定 `epsilon=1e-4` 的

`S(H) = 0.5 * sum_k log(1 + lambda_k/epsilon)/6 + 0.5 * lambda_min/(lambda_max + epsilon)`。

它同时惩罚整体几何信息不足和最弱方向相对不足。该分数仅用于选 Tile，不是定位置信度或精度估计。P47 Native NDT Hessian 特征值另行汇报为曲率诊断，不将其称为正定 Fisher 信息。

## 确定性预算选择

Distance-Based 在精确点云尚未构建前，以描述符覆盖代理为门：直到达到 95% 代理覆盖，优先选择“新增覆盖 Source 点数 / Tile 点成本”最高的 Tile，平手时选预测 Source 到该 Tile 占据描述符的平均距离较近者，再按 Tile ID 字典序；达到门槛后，按平均距离、点成本、Tile ID 继续填充预算。

Information-Aware 也先满足相同覆盖门：在带来新增覆盖且预算允许的候选中，优先选择 `delta S(H_geo) / Tile 点成本` 最高者，平手时按新增覆盖效率、Tile ID 排序。如果所有新增覆盖候选均无正信息增益，则显式计数并退回覆盖效率排序。覆盖达到 95% 后，只按正的 `delta S / Tile 点成本` 增补。此过程只读取因果预测、当前 Source 与离线 Tile 描述符；不读取本帧 NDT、未来轨迹或 GT。

每种方法均不得超过点数上限。若没有可负担的 Tile 达到代理覆盖门，选择结果记为不可行；即使通过代理门，之后的精确点云覆盖仍可能拒绝该帧。

## NDT 与评价分离

对每个预算、方法及精确覆盖可行的帧，使用完全相同 Source、P46 初值和 PCL NDT 参数进行一次真实 `align()`。不做额外优化，不按 GT 或 NDT 结果重选 Tile。P46 原始 Local CONTROL 输出直接取冻结结果，不重跑基线。

先冻结样本、Tile 集合、目标重建哈希和全部 NDT 输出，再读取 P43 条件性 Base-frame GT 作离线诊断。GT 误差只作为条件性参考，不是 Tile 选择、可行性门槛或算法输入。
