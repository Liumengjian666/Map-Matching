# P58 HIKVISION 只读存储状态分诊

## 结论

最新状态为 **STORAGE_READY_FOR_USER_INSPECTION**；此前确有多轮 `STORAGE_UNSAFE` 观察。用户确认设备已处理并要求继续后，系统重启后的日志窗口未见新的 USB/I/O 错误，进程表无 D-state，UUID 与挂载点匹配；对既有 partial 的限速只读哈希完整成功。该结论仅表示可以交由用户决定下一步，不证明写入路径健康，也不授权自动续传。

原先的用户态拷贝进程已不在进程表中，但仍观察到 PID `371233` 的 D-state 内核块设备 flush worker（`[kworker/u32:4+flush-8:0]`）。内核日志在数分钟内反复记录 USB Attached SCSI（UAS）reset、写命令超时以及 `/dev/sda`、`/dev/sda2` 的写入 I/O 错误和异步页写丢失。因此这不是可以据现有证据判定为“已恢复”的单次瞬态。

设备元数据仍能枚举出 USB 磁盘，并显示分区挂载在 `/media/jian/HIKVISION`、文件系统为 exFAT、UUID 为 `F627-4133`。**设备仍被枚举、仍显示挂载或 `rw`，都不代表介质健康或数据安全。** 日志筛查中没有看到明确的设备 offline 或 USB disconnect 行；这不抵消已记录的持续传输和块 I/O 错误。

## 本轮采取的边界

- 只读查询了进程表、当前启动的内核日志、挂载表、USB 拓扑和块设备元数据；查询均在 5–15 秒超时内返回。
- 没有对 `/media/jian/HIKVISION` 下的任何数据文件执行读写。
- 没有检查 partial 大小或哈希，也没有验证 ZIP；这些操作留待设备物理状态确认且科研总控重新批准后进行。
- 没有卸载、拔除、重启、修复或格式化设备。

## 建议

目前不要继续使用该盘，不要续传或复制数据。先由用户安全检查 USB 线缆、接口、供电、硬盘盒及设备物理状态；不要在内核仍有 D-state flush worker 时强制拔盘或强制卸载。物理检查后仍需由用户确认设备状态安全，并取得科研总控的新批准，才可进入下一轮只读核验。

本轮未恢复任何数据，也未写入 partial。文件内容通过完整顺序读取计算 SHA-256，哈希与故障前记录一致；文件仍不完整，ZIP 结构未检查。没有启动下载、复制、解压、ROS 或定位程序。
