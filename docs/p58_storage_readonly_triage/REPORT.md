# P58 HIKVISION 只读存储状态分诊

## 结论

**STORAGE_UNSAFE**。本轮只查看了系统进程状态、当前启动的内核日志和设备/挂载元数据；没有读取外盘上的 partial、没有向外盘写入，也没有启动下载、复制、解压、ROS 或定位程序。

原先的用户态拷贝进程已不在进程表中，但仍观察到 PID `371233` 的 D-state 内核块设备 flush worker（`[kworker/u32:4+flush-8:0]`）。内核日志在数分钟内反复记录 USB Attached SCSI（UAS）reset、写命令超时以及 `/dev/sda`、`/dev/sda2` 的写入 I/O 错误和异步页写丢失。因此这不是可以据现有证据判定为“已恢复”的单次瞬态。

设备元数据仍能枚举出 USB 磁盘，并显示分区挂载在 `/media/jian/HIKVISION`、文件系统为 exFAT、UUID 为 `F627-4133`。**设备仍被枚举、仍显示挂载或 `rw`，都不代表介质健康或数据安全。** 日志筛查中没有看到明确的设备 offline 或 USB disconnect 行；这不抵消已记录的持续传输和块 I/O 错误。

## 本轮采取的边界

- 只读查询了进程表、当前启动的内核日志、挂载表、USB 拓扑和块设备元数据；查询均在 5–15 秒超时内返回。
- 没有对 `/media/jian/HIKVISION` 下的任何数据文件执行读写。
- 没有检查 partial 大小或哈希，也没有验证 ZIP；这些操作留待设备物理状态确认且科研总控重新批准后进行。
- 没有卸载、拔除、重启、修复或格式化设备。

## 建议

目前不要继续使用该盘，不要续传或复制数据。先由用户安全检查 USB 线缆、接口、供电、硬盘盒及设备物理状态；不要在内核仍有 D-state flush worker 时强制拔盘或强制卸载。物理检查后仍需由用户确认设备状态安全，并取得科研总控的新批准，才可进入下一轮只读核验。

本轮未恢复任何数据。P57 既有 partial 保持原样；其内容与健康状态均未在本轮验证。

## 用户报告已检查设备后的再次系统复查

用户表示设备已恢复并要求再试。复查仍只查询了系统进程表和当前启动内核日志，没有读取外盘目录或数据文件。进程表中观察到一个 D-state 内核 worker：PID `377357`，`[kworker/u32:2+events_unbound]`。内核日志在 `16:55` 至 `17:00` 期间继续出现 UAS reset、写命令超时及 `/dev/sda`、`/dev/sda2` 写 I/O 错误；`17:01:04` 记录 USB disconnect，`17:01:08` 设备重新枚举。重枚举前仍有写命令失败和异步页写丢失。

因此用户所述的物理检查后，系统证据仍不满足恢复门槛，结论维持 **STORAGE_UNSAFE**。由于检测到新错误后立即停止，没有继续核验挂载状态、UUID、partial 大小、SHA256 或 ZIP 完整性，也没有尝试续传。

## 用户再次要求复查后的最新证据

在 `2026-10-17 18:32:34+08:00` 进行了一次有界只读复查。当前进程表未显示 D-state 进程，但内核日志在 `18:10:20` 和 `18:31:59` 两次记录 USB disconnect；每次断开后均出现 `Synchronize Cache(10) failed: hostbyte=DID_ERROR`，随后设备分别于 `18:10:23` 和 `18:32:02` 重新枚举为 HIKVISION。最近一次重新枚举发生在本次检查前约 32 秒。

这足以确认 USB mass-storage/SCSI 通信链路仍不稳定，但不能区分线缆、接口、供电、USB桥接/硬盘盒或盘体故障。最新断连后没有再读取任何设备元数据或数据文件，因此当前挂载状态、UUID 和文件可读性均未核验。最终结果仍为 **STORAGE_UNSAFE**。
