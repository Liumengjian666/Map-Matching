# 本地质量核验

7项无网络元数据／证据测试通过；不运行ROS或算法。
生产src和P60-R5归档相对START_SHA无差异。
仅新增本目录研究工具、官方小型资料和访问失败归档。

五轴核查：

- 正确性：HTTP200不等于数据下载成功；确认页和配额页分开，完整bag SHA为null。
- 可读性：目录读取、一次确认探针、离线归档分别实现，没有混入生产路径。
- 架构：未创建定位适配器、地图或伪造启动入口，blocked时停止。
- 安全：仅官方初始源、仅内盘、拒绝覆盖；确认请求固定同一file ID，不登录、不绕过限制。
- 资源：元数据每次8MiB上限，确认探针64KiB上限，没有大包或多序列并发。

上游README第3行和gamma_config.yaml第79行自带尾随空白。
为保留官方字节身份，**没有格式化这些原始资料**。
自写代码及其余归档的`git diff --cached --check`使用两个明确原始文件排除项；
不能通过清洗上游YAML让SHA变化后仍声称原文件。
archive_hashes.json覆盖33个当时已存在的代码／证据／报告对象，可独立重算。
本文件在该哈希清单生成后增加，由最终Git提交保护。

没有编译或启动NDT，因为所有生产代码未改且输入合同不成立。
没有执行外部CLI或宣称独立跨模型复核。
