# 对R10/R11结论的影响与材料接收规则

本轮没有收到作者回复或新的采集证据，仅完成现有资料盘点和请求草稿。
因此保持：

- CLOCK_SYNC_NOT_CERTIFIED
- BIAS_STABILITY_NOT_EVALUABLE
- R10_CONTRADICTION_REMAINS_CONDITIONAL

不能把“归档中没找到”写成“作者没记录”；不能把“尚未认证”写成“已经证明错误”。
没有重算R10数值，没有修改其固定bias、时间合同或门限。

## 接收后应交由科研总控核查，不自动更新历史结果

1. 首先确认材料与S1目标采集会话的绑定；不同文件应有可追溯发布/转换链，
   不能仅因同为Avia、Xsens或gamma就套用。固件/驱动版本应注明实际有效时间。
2. 时间材料应解释两个设备原始时间到ROS时间的转换，并给出独立误差依据，
   包括定义、单位、时段和测量来源。只有header相同、record差小、配置offset0、
   一般性同步说明或参考驱动源码，均不足以关闭H11-A。
3. 偏置材料应有实际设备对应的独立校准/验证来源，时间/样本/坐标系明确。
   首次校准文件可支持来源，不自动认证目标时刻的稳定性；同一LIO的bg、
   gyro均值或低角速度也不能关闭H11-B。
4. 材料缺失、受限或无法绑定时，按原文记录状态及局限，不以零值、推测或拟合补齐。
5. 作者解释可以作为来源声明归档，但未经支持记录的声明不自动等同独立量化误差证明。
   若材料指出明确违规，保留具体证据交总控决定，不在本轮修改时间或定位结果。
