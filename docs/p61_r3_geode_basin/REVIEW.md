# 有界反证与执行前复核

本轮使用Git隔离、增量实现、代码质量、反证复核技能。
只新增docs独立工具，不修改生产NDT、EKF/Coupled数学或R2归档。

第一轮独立只读复核发现并修正：
1. 单个远离非驻点nominal的真正极小值，不足以证明存在两个竞争basin。
   最终标准改为两个各由不同物理初值重复到达的驻点簇。
2. 弱平移和耦合初值在Hrt为0时可能完全相同，不能以不同ID凑重复数。
3. Schur特征方程残差增加显式守卫。

独立SciPy symmetric-pivoted solve+eigh复算100个R2 Hessian：
Schur相对差最大1.2702722826406224e-15，特征值相对差2.302808658698044e-15；
弱/强向量残差7.479570700924537e-16/3.961888796583884e-16。
整数精确时间采样独立复核20个索引一致。无align/bag/GT读取。

第二轮只读复核发现并修正：
1. verify与align必须绑定相同预注册和二进制；运行时代码的本体路径也比较Git差异。
   允许归档/保护代码改进，不允许把不同native二进制混为同一预检。
2. 全失败且没有可聚类输出时，仍输出显式表头的空簇表，不以IndexError中断归档。
   新增二进制/清单置换拒绝及空表回归测试。

11项Python测试通过。R2 nominal只读预检20/20通过，能量差及Hessian差均严格为0。
本地PCL registration.hpp:192-200在每次align重置converged、final/transformation/previous，
然后传入当前guess；同一Target对象复用不会把上一个结果隐式当新初值。
