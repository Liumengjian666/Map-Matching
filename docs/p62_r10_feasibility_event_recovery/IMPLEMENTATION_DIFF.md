# Actual C++ algorithm delta from START_SHA

All edits are new files under docs/p62_r10_feasibility_event_recovery/. Frozen R9 source is read/reused, not edited; no old result audit or old program rerun. Production remains read-only.

- events.hpp adds complete nominal-admission event reasons, independent recovery permission, and a final decision that cannot revive rejected observations. Old trigger comparison reproduces R9's actual predicate; new nonconvergence/maxiter detection does not require validation. Nonfinite pose/score, invalid SE(3), missing validation and budget guards are explicit. A legal nominal can remain when recovery is unsupported; otherwise accepted pose is NA and prediction is a Shadow record only.
- shadow.cpp is a new compiled driver adapted from the specified R9 actual source. Its nominal loop now calls detect(), checks permission before G, generates SMALL seeds only, compares the unchanged V2 pool, and calls decide() before writing an observation. R9's entire fixed/large-scale diagnostic stage is absent, not merely hidden in statistics. Native FULL stays outside the proposed pool.
- native_capture.hpp invokes exactly the original NativeNdt::align arguments and objective, but flushes RAW_OPTIMIZER_OUTPUTS immediately after the optimizer returns and before auxiliary fitness NN. Unsafe poses/scores skip fitness; safe results retain the original getFitnessScore diagnostic. RAW_NATIVE_OUTPUTS then records completed native metrics before heldout validation. This is research-wrapper safety/recording, not an optimizer or threshold change. Validation exceptions are recorded before stopping. A crash inside the native optimizer itself cannot promise a returned pose; START/exception evidence is retained and no result is fabricated.
- Coverage V2, normalized G, original NativeNdt PCL objective/configuration, preprocessing, physical bounds/dedup, paired scoring and Budget are directly included unchanged from frozen source dependencies. Only the auxiliary native wrapper's capture/fitness ordering changes. No custom objective, solver, extra direction, LARGE seeds or threshold is introduced.
- Event tests cover ordinary/old/new triggers, B4/B5 and missing coverage, unsafe values, strict.02, dedup/singleton, unsupported alternative, successful supported replacement, and final rejection/prediction-only semantics. No align in tests. A stale corrupted competitor metadata flag can still cause the inherited paired scorer to throw; this is fail-closed stopping, not accepting evidence after ignoring it.

Raw inputs retain the previous no-deskew/midpoint contract. The map has same-record dependence, and all100 historical causal initials are fixed; no new closed-loop trajectory, GT accuracy or EKF fallback execution is claimed. State-machine correctness is distinct from successful recovery.
