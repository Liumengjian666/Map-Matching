# R11冻结数学合同（运行前）

统一 T_A_B 将B变换到A。TP、T0均为T_M_L；右残差 A=TP^-1 T0。
ξ=(ρ[m],φ[rad])=Log(A)是预测LiDAR坐标中的右/body切向量。
Exp(ξ)=[ExpSO3(φ), J(φ)ρ;0,1]，不是把ρ直接作为三维平移。
J=I+(1-cosθ)/θ² [φ]×+(θ-sinθ)/θ³ [φ]×²。
Log使用 J^-1=I-.5[φ]×+(1-(θ/2)cot(θ/2))/θ² [φ]×²。
小角使用对应级数；SO3对数使用归一化四元数的主值，覆盖近π情形。
PCL float矩阵的既有SE(3)合法性容差不变；归一化只用于计算旋转Log，
不替换名义候选。重构矩阵Frobenius误差须<1e-5；否则停止。

预定统一比例 s=min(1,.30/||ρ||,(3π/180)/||φ||)，零分母忽略。
两个分量均≤1e-10（分别m/rad）时不生成方向。物理上界先扣除固定数值余量：
ε取PCL初值float机器精度（SE3运算本身仍为double），
τt=64ε(1+||tP||+.30)m，τr=64ε(1+||RP||F)+8||RPᵀRP-I||F rad；
κ=max(1,σmax(RP))。用(.30-τt)/κ、(3π/180-τr)计算比例，再向零移动一个double ULP。
κ和τr还覆盖既有rigid容差允许的float非正交误差；实际因果预测来自归一化四元数，
但函数也测试float预测输入。若坐标精度无法支持正上界则停止。
这只防构造世界坐标和相减的舍入越限，不使用分数或候选结果调幅。
种子 TP Exp(±sξ)。J(φ)=积分0到1的旋转矩阵，算子范数≤1，
故在理想旋转下实际平移≤s||ρ||；对既有容差允许的RP非正交，
实际平移≤κs||ρ||≤.30−τt，τt再覆盖世界坐标运算舍入。
