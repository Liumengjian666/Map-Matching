# R12 frozen pre-replay contract

T_A_B maps B points to A. Input is precisely the R11 raw candidate returns and validation records; no pose or loss is optimized or rewritten.

1. Recompute every raw candidate's eligibility using the actual R10 `admissible()`: finite rigid native pose and metrics, converged, relative prediction <=.8m/5deg, Coverage V2 active evidence and overlap>=.50. Active blocks derive only from frozen point counts>=10, training>=300 and B>=4.
2. Sort immutable IDs ascending, require unique IDs and id0 nominal. This equals the original R11 arrival order and makes caller permutations deterministic. Unsafe poses remain raw but never enter geometric comparisons.
3. Freeze greedy group anchors: each valid pose joins the first prior anchor within the unchanged actual `duplicate()` <=.10m AND <=1deg; otherwise starts a group. Membership is never recomputed after representative promotion. No connected components or transitive closure. Every member is close to its original anchor, NOT necessarily every other member or a promoted representative. This limitation is explicit.
4. If a group has admissible members choose its lowest-ID admissible member, otherwise keep the anchor. Native score, losses, GT and recovery outcome never choose the representative. All raw records remain accessible in Pool.original and frozen source CSVs; Pool.raw is a separate derived canonical view with recomputed eligibility/representative indices. The original argument/metadata is never overwritten.
5. Decision candidates are usable representatives. Evidence competitors are usable representatives UNION RAW_NOMINAL_ANCHOR(id0). A usable evidence record requires safe native pose/metrics and valid active losses, not necessarily admissibility/convergence. If nominal evidence is unavailable, no supported replacement is inferred.
6. An alternative representative j>0 is robust-supported only if it is admissible and, against EVERY other evidence record k, D(j,k)>.02, with at least one real opponent and available nominal anchor. D=min_w sum w_b*(loss_k-loss_j), sum w=1, 0<=w<=2/B, computed by frozen `coverage::paired()`. Singleton representatives do not remove nominal evidence. This intentionally defines an evidence set, not a second selectable physical pool.
7. Native score and held-out mean rank the SAME representative pool after admission. Robust selection uses that pool and the explicitly recorded evidence set. Final selection rechecks support and admission; otherwise retains admissible raw nominal or emits NO_ACCEPTABLE_MEASUREMENT and Shadow prediction-only fallback.
8. Physical distinctness means a candidate is outside the original nominal-anchor group, not merely id>0 after promotion. Promotion within a duplicate group is feasibility preservation, not a new branch or attractor. No new physical candidates can arise in an offline replay.

Non-transitivity fixture: positions 0,.09,.18m, identical rotations. Groups {0,.09},{.18}; when .09 becomes feasible representative, .18 is NOT merged. Multiple legal members select minimum ID. This retains frozen sequential anchor grouping on R11 data, but intentionally changes the representative contract only.

Fixed acceptance counterexample: R11 proposed64/id1 must become representative over inadmissible id0, but must still compare to raw id0. D(1,0) remains -0.001052113786269879, so no supported replacement is expected. No threshold changes or success-dependent tuning permitted.

Execution: exactly one C++ replay of100 frames x2 arms. CONTROL invokes original deduplicate/coverage::select/feasibility::decide. PROPOSED invokes the new header using original admissible/duplicate/paired functions. No NDT object, seed generation, map loading, trajectory estimation, GT, EKF or ROS. Unit fixtures separate from real replay.
