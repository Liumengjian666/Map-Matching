# Implementation delta

- `tools/coupled.hpp`: retained the R15 native-PCL score, geometry and coupled block solver; split map configuration from source switching. `configureMap()` performs the PCL 1.10 `setInputTarget()`/Gaussian-grid initialization once per map, and `setTraining()` changes only the Training source while asserting a complete Gaussian-grid fingerprint is invariant. Frozen NDT getters are checked at configuration. The legacy-geometry conversion diagnostic shares transformed points, associations, residuals and Gaussian weights, but uses an algebraically equivalent alternate Jacobian factorization; it is not bitwise-identical Jacobian arithmetic.
- `tools/piecewise.hpp`: added `NominalAssociationBranch`. It records each point's actual PCL nominal leaves and stable voxel IDs, anchors continuous SE(3) residual motion at the exact float-transformed nominal point, evaluates the PCL Gaussian score on those fixed memberships, differentiates only that branch, and reports dynamic membership changes separately.
- `tools/run_piecewise.cpp`: loads only the frozen 5 R13 + 20 R14B records, verifies source/split and map identities, uses one grid object per map, requires each reused-grid nominal score to agree with the frozen R15 fresh-grid score within 1e-9, writes all matrices/objective/coverage/runtime outputs, and makes zero `align()` calls.
- `tools/test_piecewise.cpp`: extended the R15 synthetic math tests for exact grid reuse vs independent one-frame construction, frozen grid immutability across source switching, fixed-branch derivatives at a dynamic association boundary, the R6 algebraic coordinate-conversion identity under test conditions, single exploratory tail direction, paired Weak-only/Coupled solve, and rejection of a nonfinite local model.
- `tools/verify_parent_inputs.py`: read-only streaming verifier for the 131 identities from the R15 frozen input manifest.

The historical R6–R14 dependency sources remain unchanged. Their hashes and the implementation source hashes are sealed in `SOURCE_PROVENANCE.json` and `CODE_FREEZE.json`. The production worktree and all R6–R15 historical result files remain out of scope.
