# 有界文献比较：耦合子空间精修的重合与差异

检索与阅读日期：2026-10-22。只深入阅读下列6篇直接相关论文/预印本；该范围用于定位可能重合，不构成系统综述或“全球首创”证明。技术描述以论文正文为准。

## 论文对照

## 对任务A–F的直接回答

- **A — 特征值/退化判断：有。** X-ICP用方向性局部可定位性；GenZ-ICP用条件数分析；DCReg对解耦子空间做特征分析。故“特征值阈值识别退化”不能单独作为创新点，且这些论文的具体度量并不等同于R15B冻结的 `lambda_i/lambda_max <= 0.01`。
- **B — Schur/交叉耦合：有。** DCReg明确以Schur补量化旋转—平移交叉耦合。Schur补本身和块消元不构成R15C创新。
- **C — 运动预测/先验：有。** SuperLoc在风险触发时把替代里程计相对位姿作为先验因子联合优化；VICET将扫描内运动状态纳入NDT。运动先验本身不是新点。
- **D — 改弱方向后条件优化强方向：有相邻思想，精确实现未证同一。** DCReg处理子空间间耦合并用于预条件；X-ICP按可定位性约束更新；SuperLoc联合使用先验。但在这6篇中未发现完全相同的“冻结NDT候选与弱向量 (d_w)，只对比是否加入 (H_{sw}d_w)，并在同一受限候选上做动态NDT及结构留出归因”的合同。由于这只是标准分块二次模型的直接推论，当前检索不足以支持原创性声明。
- **E — 固定先验地图NDT：有。** VICET明确报告HD地图NDT定位；因此“固定地图+NDT”不是差异点。其主要问题是扫描内运动畸变，不是R15C局部耦合归因。
- **F — 当前最小技术差异：** 在PCL 1.10 Gaussian目标的名义关联分段局部模型内，用统一物理尺度的谱尾方向承载预测投影 (d_w)，保持同一 (d_w)、(H_{ss})、(g_s)、(lambda) 和信赖域，直接对照“普通强向梯度响应”与“额外 (H_{sw}d_w) 响应”；并在相同动态关联PCL目标及未参与优化的Coverage V2扇区上评价。R15B所有25帧均未达到正式0.01退化判据，所以这是**探索性局部机制归因**，不能包装为正式退化恢复。

## 查新结论

**NOVELTY_NOT_ESTABLISHED；无证据可称“与既有方法完全相同”，也无依据称“首次提出”。** 已知组成元素与DCReg、SuperLoc、X-ICP、VICET分别有明显重叠。R15C的价值是测量交叉块对现有R15B改善的独立边际贡献，而非把Schur补、特征值或运动先验重新命名为原创算法。即使本轮出现有利的25帧结果，仍须另行判断统计稳定性、正式退化场景适用性、独立精度证据与新颖性。
