# 独立 NDT 失败实验预注册草案

**DRAFT_ONLY · NOT_FROZEN · NOT_AUTHORIZED_FOR_RUN**

R18 的 G3—G5 未通过。本文件只规定下一次合同需要预先冻结的内容；没有选择正式序列窗口、设定事后阈值或执行 NDT。科研总控需先审查作者提供的坐标、杆臂和时间证据，再批准独立实验。不得直接执行本草案。

## 准入后才可冻结的输入

1. 固定一个官方 FEE 序列、一种官方交付形式及各文件 SHA256。由于直链扫描和 ZIP 同路径成员大小不同，必须选定一种并记录版本，禁止混用。
2. 固定独立 BLK360 地图、地图到 Tracker 参考系的测量链及棱镜到 LiDAR 的杆臂；明确独立参考只评价哪些自由度。若只证明位置，不计算或声称独立旋转误差。
3. 从原始 bag 核实扫描 `header.stamp/frame_id`、Tracker `header.stamp` 与 record time、点内时间字段和实际匹配误差分布。预先规定最大匹配差及缺口处理；不以定位误差反推时差。
4. 在读取任何测试参考误差或 NDT 匹配质量前，依公开原始点云几何和时间顺序确定**唯一**有界连续窗口，记录全部帧 ID、时间、Source SHA。只允许一次地图系初始化锚点，后续使用因果预测。窗口长度、选取规则和停止门由下一轮正式合同预先确定，本轮不捏造。

## 固定方法及评价

- 冻结 R17 NativeNdt 的 PCL 参数：resolution 0.8 m、step 0.08、epsilon 0.001、max_iterations 40、outlier_ratio 0.55。复用已验证的 Source 预处理、因果预测、Coverage V2、事件/准入输出；FEE 格式适配须先测试，但不根据效果调 NDT。
- 先冻结每帧 Prediction、Raw Full NDT、可用 Split NDT、Overlap/Score/几何特征值、预测差异和决策；随后才读取独立参考评价。保留所有困难帧和失败调用。
- **H1**：是否出现原生 NDT 收敛但相对于有资格的独立参考明显偏离的帧。偏离阈值和参考精度界限须在正式实验前定义。
- **H2**：同一冻结窗口是否同时含有害与有益的大幅 NDT 修正。只有经独立参考可比较的分量才能分类；不能以预测差异、Overlap 或 Score 自行定义正确性。
- **H3**：在不把参考输入在线规则的前提下，现有 Overlap、Score、预测差异与几何约束能否区分 H2 两类修正。阈值和比较指标须预先冻结；不得用测试参考调参后在同窗口报独立验证。
- 报告绝对数量、分母、置信区间或有限样本不确定性、每帧时间与参考资格。若 Tracker 仅支持独立位置评价，旋转表现记 `NOT_EVALUABLE`；地图配准生成的姿态仅可作非独立补充。

## 停止门

任何 G1—G6 合同不全、参考帧时间缺口超门、地图覆盖不足或输入身份不一致，停止正式实验。只使用预注册的一个窗口；不根据已见 NDT/参考结果移动窗口或增加序列。若没有收敛错误盆地或两类修正并存，照实报告 `NOT_OBSERVED`，不追加搜索。
