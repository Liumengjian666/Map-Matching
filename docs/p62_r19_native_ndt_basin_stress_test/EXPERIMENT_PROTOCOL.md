# R19 frozen protocol (written before input prescreen and NDT)

Start commit `35ce3e4fd5f154f447b516171d08b9111f01810c`. Dataset: local Newer College `01_short_experiment`; official Leica prior map; R14B conditional Base-frame transform. The official registered poses are map-anchored benchmark reference, not independent motion capture. R16/R17 raw7570 region is excluded by selecting only the final 30% of sequence time.

## Window choice, without map or reference pose values

Use canonical `docs/p62_r14b_newer_college/LOCAL_SCAN_INVENTORY.csv` ordered by integer nanoseconds. Find the first scan with `(stamp-first)/(last-first) >= 0.70`. From there sample every 10th ordinal, at most 800 total unique PCD reads including the final windows. On each sampled PCD use exact R14B native PCL reader/preprocessing (finite XYZ; 0.5–80 m; 0.25 m voxel; 1,400 cap). Compute scanner-frame XYZ sample covariance and `lambda_min/lambda_max`. This is an input-only proxy and never a formal NDT degeneracy label. Choose the minimum-ratio sample as weak candidate, earliest ordinal on an exact tie. Center a 61-frame window on it, shifting only to remain in final-30% bounds. Among samples whose centered 61-frame windows do not overlap the weak window, choose the maximum-ratio sample as strong control, earliest ordinal on an exact tie. If either cannot be found, stop. Read all 122 selected frames, verify schema/source and freeze 61 IDs, timestamps, file SHA256, source FNV before any NDT. Frame 0 of each window is the one-time reference anchor; frames 1–60 are evaluations. No resampling or third window.

## Four optimizer-only causal arms per window

C0 uses `T_M_L` obtained once from anchor `T_M_B * T_B_L`. Let the anchor scan preprocessed XYZ covariance's largest horizontal eigenvector be `u_L` (XY plane, Z=0), with deterministic sign: its first nonzero component is positive. Convert once to map vector `u_M=R_M_L(anchor)u_L`. C1/C2 anchor translation is `p_anchor +/- 0.8 u_M`. C3 anchor orientation is `R_z(+8 degrees) R_anchor` around the map Z axis; translation unchanged. All four arms use the same 61 scans, one fixed 50 m anchor-centered Leica ROI, 0.20 m map voxel and frozen NativeNdt parameters. Do not use evaluation reference values, map matching outcomes, or errors to select the input vector.

For each arm, predict causally from its own accepted optimizer-only history using R14B right/body constant velocity; with less than two completed poses or after a quality fallback, reuse last pose. Run one native Full PCL NDT per evaluation frame. Record raw pose/score/convergence/iterations, Coverage V2, Overlap@0.5m, correction from prediction, and map-conditioned R9 geometry `G` at the raw Full output using frozen Training Source. **Optimizer-only feedback** accepts finite valid SE3, converged native score/fitness, valid Coverage and Overlap >=0.50; it does not apply 0.8 m/5° policy bounds. Invalid output holds the previous state and disables extrapolation. **Admission shadow** separately records whether the unchanged R10 0.8 m/5° bounds would reject; shadow never changes optimizer-only state. A raw failure is not an erroneous local minimum.

## Output freeze, reference, and evidence levels

Run at most 2 × 60 × 4 = 480 Full aligns, plus at most eight stability aligns only if a preregistered candidate meets the persistent suspect gate. No Split, EKF, Coupled or Recovery. Freeze native CSVs with SHA256 before reading any evaluation reference pose values. Then compute exact-timestamp benchmark-relative translation/rotation errors for raw NDT, predictions and causal outputs. A Level-1 sensitivity frame requires two finite converged Full terminal poses on identical scan/map/parameters separated by >0.10 m or >1°. Level-2 suspect requires C0 error <=0.3 m and <=3°, a disturbed arm error >0.5 m or >5° and worsening on that same component >=0.3 m or >=3°, for >=3 consecutive quality-valid frames. Thresholds are research screening criteria, not algorithm admission parameters and not independent physical truth. Only a stable, separate terminal-pose result with quality/score and up to eight bounded repeat aligns may be classified `STABLE_DISTINCT_CONVERGENCE_OBSERVED`; otherwise use the contract's lower evidence classifications. No post-result parameter or window changes.

## Fixed implementation interpretation

`NativeNdt::geometry()` is the R6 Gaussian map-conditioned approximation, **not** PCL's exact optimizer Hessian. Weak count uses existing ratio <=0.01 and is diagnostic only. P45's tile manager is not used: its offline 0.20 m map/ROI handling is relevant, while per-frame tile selection would change the target and confound basin comparison. Use one fixed map per window.
