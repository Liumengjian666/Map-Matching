# 数学方案（未实现、未验证的研究合同）

## 1. 状态、坐标与原生目标

T_M_L=[R,p;0,1]∈SE(3) 将雷达点变换到固定地图 M。若有合法 IMU 外参，T_M_L=T_M_I T_I_L。scan-end 为位姿参考时刻；本轮未处理真实传感器输入。

沿用归一化局部 chart：p=p0+0.8η_t，R=Exp([η_r]×)R0，η=(η_t,η_r)∈R6；0.8 的单位 m，旋转系数为1rad。物理边界分别约束 ||0.8η_t|| 和 ||η_r||，不能直接比较 m 与 rad 的原始 Hessian 特征值。

生产 PCL NDT 是邻域高斯得分，不直接等同于高斯负对数似然。按当前安装 PCL 1.10 `registration/impl/ndt.hpp` 的 score_inc 定义，最小化

E(T)=-(1/N) Σ_i Σ_{c∈C(Tx_i)} a exp(-b q_ic(T)/2)，
q_ic=(Tx_i-μ_c)^T Σ_c^{-1}(Tx_i-μ_c)，a=-gauss_d1>0，b=gauss_d2。

邻域查询、有效体素/协方差保护、常数和导数须原样复用冻结原生实现，并通过 ObservablePclNdt 数值一致性核验；不能改成自己的新 NDT。g=∂E/∂η∈R6，H=∂²E/∂η²∈R6×6。邻域切换使整体目标分段光滑，不能对跨邻域步长假定二次模型处处有效。H 可能不正定，不是已认证 Fisher 信息或协方差。

## 2. 几何方向与耦合

若需要稳定方向，可另构造 PSD 近似 G=Σ a_ic J_ic^T Σ_c^{-1}J_ic /N，a_ic≥0，J_ic=∂(Tx_i)/∂η∈R3×6。它只用于方向定义，不能冒充原生 Hessian；构建开销要计数。取 G 的相对小特征值 λ_i/max(λ_max,ε)≤0.01 为候选弱方向 W∈R6×d，S∈R6×(6-d) 为正交补。该0.01是待审批的新实验定义，不回写 P60/P61 旧阈值，也不是定位错误判据。λ_max太小/无有效方向时记 NA，不强造方向。

η=Wu+Sv，二次模型块为 A=W^T H W，B=W^T H S，C=S^T H S。若使用 H 的精确特征基，B 在该点为零；不能把数值零耦合写成强方向收益。若在弱位移点重新线性化，则必须说明基冻结而导数改变。

在 C 正定、条件数≤1e8 时，求解 Cx=g_s、CY=B^T（不得形成逆矩阵）：

v*(u)=-C^{-1}(g_s+B^T u)，H_eff=A-B C^{-1}B^T。

只有 H_eff 也正定且条件允许，才有该二次模型的有限极小解。LDLT 可逆不等于最小化成立。若用 H+λI，必须将其称为阻尼模型、与对照使用相同 λ=1e-3（归一化目标单位），记录 λ；不得根据 GT 或结果逐帧搜 λ。守卫失败拒绝此候选，不任意修补谱以获得收益。解还须满足总修正平移≤0.8m、旋转≤5°和原生得分验收。该消元是经典代数；本轮合成测试证明它等价于完整阻尼二次求解，不是原创算法证明。

## 3. 训练与验证：不能伪称统计独立

预处理后至多1400点按 scanner-frame 方位角固定为16个半开扇区（+π归到-π）；偶数扇区仅训练，奇数扇区为8个验证块。每个验证块至少10个有限点，训练至少300点；不足记 NOT_EVALUABLE。不得旋转扇区方向挑结果，不能将点补入训练。无机器人前向轴认证时只称 scanner-axis 分区。

分割发生在本帧名义 align、方向估计、种子生成之前。验证点不参与名义优化/方向/种子。传感器和空间相关性仍然存在，尤其相邻扇区并不 IID；无基于该拆分的置信概率/独立验证集泛化保证。历史状态可影响预测，故时间相关也需披露。

CONTROL_FULL 使用全部原合同 Source；CONTROL_SPLIT 只用训练点。二者都是必要对照，不能将分点损失掩盖为算法收益。CONTROL_FULL 输出不能回灌主方案候选池。所有比较使用同一地图、初始预测和预处理；不同训练点集须明确列出，而不能谎称 Source 完全相同。

## 4. 固定候选与预算

主方案 B：训练 Source 进行一次原生 NDT 得到 T0。触发时在 T0 归一化 G 最弱方向的±0.30m平移尺度构造至多2个种子；方向含旋转时统一缩放，使平移≤0.30m且旋转≤3°，零分量不造成除零。每个种子最多一次原生 align，与 T0 同 Target、同参数。方向退化或种子重复则少做，不补搜索维度。记录真实有限候选集合。

物理不同候选以0.10m且1°以内去重；无新候选即弃权恢复，不凑数量。候选输出总修正相对共同预测超出0.8m或5°则拒绝，不截断成另一个候选。阈值为研究预注册，非生产变更。

次级耦合仅用于 A/C 消融：冻结该点的 W/S，在合法弱位移后再线性化，求强向条件步；等预算弱组第二步仍限 W，强增量严格0。相同首个弱步、λ、物理界、条件/残差/得分守卫。每个被精修候选最多2次 jet、4次额外 value，无额外 align。C 最多3候选，即6 jet/12 value；C_WEAK 相同上限。不是“同预算=同耗时”。普通帧不做这些额外计算。

## 5. 验证损失、直接成对优势与弃权

验证块 b 的损失 ℓ_b(T)=mean_{x∈b} min(d_NN(Tx,map)^2/(0.5m)^2,1)∈[0,1]。空块/非有限数据是不可评价，不填零。对应率定义另报，最近邻支持不等于绝对位置正确。

W_B={w∈R_B:Σw=1,0≤w_b≤2/B}，B=8。

D(j,k)=min_{w∈W_B} Σ_b w_b[ℓ_b(T_k)-ℓ_b(T_j)]。

正 D 表示在该**确定性权重集合**中 j 均比 k 损失小。不提供随机独立或安全概率保证。排序损失差后向最小项依次分配上限2/B即可计算。**min_w loss(k)-min_w loss(j) 不等于 D(j,k)**；二者的最坏权重可能不同，本轮反例已加入测试。

有效候选还须总体 Overlap@0.5m≥0.50；要替换 T0，候选 j 对 T0 与所有其他去重后的候选均满足 D(j,k)>0.02。多项不能唯一支配或都未过门则 AMBIGUOUS / NO_SUPPORTED_RECOVERY，不强选。几何相同但物理不同的重复走廊会使 D≈0，正确输出不确定；有限集合中胜出也不排除未搜索位置的别名。

## 6. 可选运动证据，不是 NIS 一票否决

仅当时钟、bias、外参及其误差界均独立认证，才能计算 e_j=||Log(ΔR_gyro^T ΔR_j)||，ρ_j=min((e_j/σ_R)^2,1)。σ_R 必须来自独立标定误差模型，不用 NDT 残差拟合。否则该证据标记 MISSING，主实验 β=0，而不是把 e_j=0。

有认证的另行实验才可用 D_joint(j,k)=D(j,k)+β(ρ_k-ρ_j)，β固定；有界软项不能认证绝对分支正确，也不能消除平移歧义。本轮不冻结未经认证的 σ_R/β 数值，不允许因此偷偷启动“联合IMU实验”。

## 7. 事件与回退

仅当训练 NDT 不收敛/达到迭代上限，或 T0 的验证块损失中位数>0.25，才请求恢复预算。阈值不在测试集调节。空间块验证参与触发和筛选，具有选择效应，不能随后视为未使用的最终测试证据；外部参考评价另行保留。

普通帧额外 align=0（验证 NN 计算仍有成本）。触发帧最多2，100帧试验总额外 align最多20；按时间顺序消耗令牌，耗尽不补发，记录 BUDGET_EXHAUSTED。候选拒绝后仅允许已有合法预测路径继续或停止，不把拒绝变成虚假成功观测；不改 EKF/OOSM 本轮实现。

## 8. 复杂度和限制

名义 NDT 沿用原成本；验证每候选 O(N_val log M)，方向构建 O(N_train·6²)，块优势 O(K² B log B)，K≤3。额外优化≤2次align/触发帧，总预算显式有限；Target可共享，但须报告构建/常驻/缓存内存。不能由这些上界声称10Hz。

本轮 offline_math.py 只测试小矩阵和人工损失数组，不是 NDT、候选恢复或定位实现。真实收益、原生导数合法性和预算公平性都尚未验证。
