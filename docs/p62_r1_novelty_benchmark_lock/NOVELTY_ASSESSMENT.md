# 创新候选决策：一个主方案，一个次级假设

## 主方案（推荐先验证，不等于批准实现）

**Budgeted Selective NDT Recovery with Structural Holdout Evidence**：预算约束、结构留出证据门控的选择性 NDT 恢复。

问题不是“最低 Hessian 特征值是否小”，而是：同一帧固定候选池中，是否存在一个候选在未参与其优化的空间结构块上，对基线和可分离竞争候选都具有稳健的成对优势？无法区分时允许输出 AMBIGUOUS，而不强行挑最好看的分数。

实质差异的**待验证主张**是“有限计算决策机制”，不是已有模块名称的并列：

1. 训练/验证分割先于名义优化、方向构造和任何种子生成，明确杜绝当前帧验证数据泄漏；不声称空间块相互独立。
2. 决策使用同一块上的**成对损失差的最坏权重优势**，不是两个稳健分数之差。
3. 普通帧额外 align=0；触发帧最多2次额外 align；独立记录验证计算和衍生计算，不能用平均耗时掩盖搜索。
4. 只认证提供的有限候选集合，不声称排除所有未搜索重复结构分支。
5. 时间/偏置/外参无法认证时，运动证据禁用且明确缺失，不以零残差冒充支持。

上述各项也不是自动的新颖性证明。PCMN、PC-FCHT、RegScorer 是最直接的反例；X-ICP、ICA、SuperLoc 则覆盖子空间及运动先验。必须完成最近方法的相同候选池对照，才能决定是否有可发表增量。**当前原创性状态：NOT_ESTABLISHED。**

## 次级假设：有界耦合精修

将耦合精修保留为可关闭的候选改善模块，不再独立宣称其为论文核心。Schur 消元与完整二次求解等价；在同一 Hessian 的精确特征基上，名义点强弱交叉块本来为零。只有位移点重线性化或采用不同几何基时可能出现交叉块。即便存在，也不证明有实际收益。

必须与**等 jet / value / align 上限的二次弱方向精修**比较。若收益不成立，删去该组件及相关贡献主张，不为保留“Coupled”字样修改假设。

## 为什么不直接采纳原暂名作为最终创新

“Evidence-Gated Coupled Subspace Refinement with Event-Triggered Candidate Recovery”可作为组件树名称，但不能先假定每个组件都必要。原 P53 已有负面等预算证据；R9–R11 未证明 Raw 位姿是错误局部极小值，更未证明放开限步器有效。因此本轮推荐优先 B（候选决策），A（耦合精修）由消融决定去留。此为提交总控审议的方案调整，未修改生产源码或科研冻结主线。

## 通过/失败的含义

- 如果仅训练 NDT 分数改善：不支持方法成功。
- 如果留出支持改善但外部参考误差未改善：只能说明验证量不足，不能改写为定位贡献。
- 如果降低误接纳却大量拒绝正确观测、降低可用率：不支持可靠性收益。
- 如果平移改善但旋转或 P95/Max 风险扩大：不通过联合准入。
- 如果仅 Exp18 改善：仅单序列结果，不能宣称泛化。
- 如果时空/参考合同未闭合：不得运行正式精度比较；不是算法失败。

唯一优先下一步见实验预注册的 G0：先对选定 Exp18 做实际文件、坐标、时间与参考独立性准入。此轮不自动实现候选，不推进 GEODE 支线。
