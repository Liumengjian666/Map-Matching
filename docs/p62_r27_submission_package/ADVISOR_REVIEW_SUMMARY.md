# 导师审阅摘要（不超过两页）

## 1. 提出了什么

题目：Gate-Aware Budgeted NDT Recovery for Prior-Map LiDAR–Inertial Localization。方法冻结为C+G：将优化前距离／覆盖几何门改为诊断，让原生NDT实际运行；优化后的基本质量与Coverage Consistency Mean≤0.30仍严格保留。名义失败时，只允许固定地图Yaw±5°的两次重启，每60帧额外调用≤12次。真实IMU继续传播，拒绝时不伪造地图观测。不提出新NDT目标函数、新多初值原理或新EKF模型。

## 2. 为什么值得发表

研究一个实际的职责冲突：错误预测下的前置几何门可能禁止本可恢复的匹配，而“允许运行”又不等于“可以融合”。G-only的负消融与C+G的真实因果轨迹将两者区分。价值在于可追溯的传感器融合系统设计、失败机制与工程收益；尚不能据此认定达到SCI期刊所需创新强度。

## 3. 实际精度收益

Newer College W1/C3完整60帧真实IMU–NDT–EKF：

|条件|平移RMSE|旋转RMSE|地图观测|额外NDT|
|---|---:|---:|---:|---:|
|原系统|7.986422m|13.052649°|0/60|0|
|G-only|7.986422m|13.052649°|0/60|0|
|C+G|0.209943m|2.984149°|57/60|8|

G-only的60次名义NDT全部收敛，但全部被优化后质量门拒绝；C+G在raw2603首次融合重启观测。前两帧大旋转误差没有删去，C+G最大旋转误差仍为11.245245°。这是已暴露开发窗口上的参考相对误差，不是独立动捕精度或跨场景验证。

## 4. 资源代价

C+G回调Mean/P95/Max为55.304/111.302/1006.031ms；NDT与EKF同时采样峰值合计392536KiB，未含发布器、Deskew和RViz。不能宣称10Hz通过。G-only为110.496/179.406/977.302ms，轨迹及优化工作不同，不能据此宣称重启必然加速。历史300帧局部地图实验NDT进程高水位内存775308→138200KiB，下降82.2%；稳态匹配7.086→8.079ms，最大平移及旋转RMSE有所恶化。不能扩展为整机节省82.2%。

## 5. 与最接近方法的区别

2Fast-2Lamaa提出连续距离场与定位／建图；SuperLoc预测对齐风险并融合运动先验；Koide2024用滑窗紧耦合点云／IMU因子；Autoware已有NDT诊断、准入、初始定位搜索和多初值协方差功能。本文仅主张特定前置门与固定预算恢复的因果交互，不主张首创门控或多初值。公开全序列里程计ATE及2Fast的0.128m定位结果单列，不能与本60帧结果排名。

## 6. 当前不足

决定性C+G收益仍来自一个已参与开发的短窗口；尚无同协议外部竞争基线。官方参考由Ouster对Leica配准生成，Base/CSV轴定义缺少直接导出身份绑定；不能称独立物理真值。部分历史硬件记录不完整。相对准入存在正常初始化反例并已排除。机器狗虽有数据与地图，但物理外参来源未闭合，未完成新对照。作者、单位、基金、通信作者、AI辅助披露范围和公开归档地址均需作者确认。

## 7. 建议期刊

优先IEEE Sensors Journal，按传感器数据处理与系统集成定位，已生成7页IEEE双栏可编辑LaTeX稿及PDF、图形摘要和补充材料。Measurement Science and Technology为备选，但其明确要求测量方法进步及不确定性说明，并不天然更容易。不能把版式符合等同于最低科研证据已通过。
