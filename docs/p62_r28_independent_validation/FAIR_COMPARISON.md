# Fair-comparison disposition

No A-grade external comparison was established. Both external integration and internal independent runs stopped before formal localization because reference initialization and evaluation cannot be certified against the ambiguous file convention.

Existing R26/R27 full-sequence published results remain B-grade background: different tasks, durations, alignments and initialization. They are not promoted into a matched-window ranking. No speedup or accuracy percentage against an external algorithm is calculated.

For a future authorized run, one external method at most must share the preregistered scans/IMU, surveyed map, valid anchor/C3 lever-arm initialization, sample times, error convention and hardware. Different frontends/map crops/filter rates must be disclosed. GICP in this EKF would be an algorithm-level controlled baseline, not an official complete external localization system. One-frame optimization scores cannot substitute for complete causal trajectories.
