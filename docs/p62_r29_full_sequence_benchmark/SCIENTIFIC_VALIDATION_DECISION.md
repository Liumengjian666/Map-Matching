# 正式结果：完整执行，但完整定位验证失败；按安全条件停止

## 执行与科学结论分开

- 完成 Koide **indoor_easy_01** 正常初始化的 A/B/C/D 四条独立因果轨迹。共同 anchor raw4，连续评价 raw5–2027，共2023帧/条；未重置或删除跟踪失败片段。
- 2023帧均有有限的实际 EKF 输出；2022帧满足冻结参考时间合同。raw1336估计保留，但参考括号间隔200.097ms>150ms，误差不可评价；它不是零误差或成功恢复。
- 本序列为 **Azure Kinect 深度点云+真实IMU**，不能称作已完成新的旋转式LiDAR–IMU完整序列验证。真正完整LiDAR序列目标本轮尚未完成。
- 所有四组均出现持续参考相对跟踪失败；工程因果数据流执行成功不等于定位验收成功。

## 主要判断

**C+G 与 G-only 的2023帧可评价位姿、时间戳及接纳/融合决定逐项完全相同。** C额外执行132次原生Full NDT，131个终值与同帧名义解超过0.10m/1°重复界限，但额外候选基本质量通过0、绝对质量通过0、入选0。因此本轮没有建立预算多初值的独立收益，也没有观察到由它产生的真实恢复。

C与B平移/旋转RMSE均为630.506992m/16.232952°。A为3995.527789m/46.259674°；D为19.576787m/106.280110°。C优于A的两个RMSE不能归因于多初值，因为B已得到相同轨迹。D的旋转更差，也没有成功解决定位问题，不能把它包装为可靠精度基准。

但相对事先冻结的合理原生基线D，C正常初始化的平移RMSE恶化610.930206m，超过0.03m安全界限；旋转则改善90.047157°。这是显著的多指标权衡和正常定位副作用，不是全面优于D。按预注册OR规则触发安全停止。

**不启动 Easy C3、Hard C0/C3、Newer College H_B/H_C完整运行或外部框架复现。** Hard资产及转换保留。Newer College未运行的直接原因是本轮安全停止，不是重新用CSV语义问题阻断全部研究。没有调整质量门、NDT参数、搜索方向或预算。
