# 限制与反例（不得升级结论）

1. 100帧为按时间冻结的最前窗口，约10秒、预测运动很小。0真实触发，未产生恢复候选；因此真实G、弱方向种子、候选去重后的竞争分支和留出判别均未获得实证。不能据此说恢复成功或失败。
2. 18类合成测试覆盖实现合同，不是18次真实算法实验。两次合成原生align与200次真实align分别统计。候选预算不是“测试使它触发”。
3. 原生收敛、NN支持、块loss均不是绝对误差。没有GT、ATE、RPE或独立位置真值，不能判定某个位姿正确，也不能认定错误盆地。
4. 历史记录只提供冻结共同initial_guess和身份，不将其当真值；所有本轮NDT输出由当前真实Source实际计算。Shadow不反馈下一帧，不能称闭环轨迹改善。
5. 原地图与loop2同记录依赖，非独立跨会话先验地图。结构留出只约束本帧候选优化，不消除地图、历史状态和扇区间相关性。
6. 稳定算法当前配置raw/中点、Deskew=false；首帧没有IMU前置包围，不假装完成scan-end Deskew。独立运动证据未认证，β=0，不以预测姿态代替独立gyro证据。
7. 所有研究对照使用真实0.8m Gaussian Grid；生产Target/resolution调用顺序不同，未修生产。CONTROL_FULL不是历史生产定位器逐数值等价的重放。
8. FULL优化使用完整Source，包含奇数块，其块loss只可作诊断。FULL/SPLIT不同Source输出差异不是同Source多盆地证据；平均原生得分、fitness也不能跨不同Source直接判优。
9. 单候选池中Native和mean保留T0，robust弃权恢复，是规则运行结果，不证明选择器有实际区分力。没有候选的情况不能伪造误接纳/误拒绝率，这些率为NOT_EVALUABLE。
10. 总墙钟和RSS包含两基线、评分、地图/100帧预载，不是单独生产PROPOSED时延/内存。0触发不能外推到预算耗尽或退化重负载；不宣称10Hz、100MiB或长段稳定性通过。
11. 首次main前加载失败是真实失败，保留未覆盖。研究子进程加载修复不代表全系统兼容性认证。
12. NCLT只读官方预筛，不具备实际两会话重叠、独立RTK评价或存储准入。高频联合SLAM参考不是独立6DoF测量真值。本轮不更换日期补证据。
13. 核心创新仍NOT_ESTABLISHED；真实触发/不同候选/判别及独立精度收益均须另行批准验证。本轮不增加Coupled、Recovery反馈或任何生产修改。
14. 单候选Native/Mean的min_pairwise_advantage=1为实际记录器哨兵，无成对比较时无定义，解释为NA，不作几何/判别证据。Python70顶点oracle存在但本真实窗口调用0次；非平凡成对数值复核仅来自合成测试。
