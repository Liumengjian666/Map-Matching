# 固定16扇区的全段适用性

## 方法与可追溯性

预检规则及实际C++源码先在15e2bf1d8de8dd6877cf45c141eaa6f773ebdb90提交，再执行唯一全段预检。Python只传输原始XYZ/offset与身份；距离过滤、VoxelGrid、1400点采样、点序、FNV与扇区均在真实C++路径执行。200个既有真实夹具与冻结R7路径逐项一致。10905帧全部读取，其中10900帧有同身份历史Source记录，点数/FNV全部一致，无静默修补。剩余5帧没有合法历史因果初值，不能凭结构合格进入Shadow。

`NATIVE_FULL_SCAN_ELIGIBILITY.csv`是原始C++输出的完整副本；`FULL_SCAN_ELIGIBILITY.csv`只增加时间/初值资格和描述性运动字段，不使用Python重新处理点云。每帧结构门与最终窗口时间/初值门分开。第一帧缺完整IMU起点包围，运动统计为NA，而不是虚构0角速度；窗口资格仍继承R7清单。

## R6、R7及运动关系

R6首100帧结构合格100/100。R7高运动100帧仅4/100合格，训练全部达标，但验证块0/1/7分别失败25/22/76帧。直接原因是既定Source与固定验证扇区占用不足，并非训练点不够；不能把过去输入失败当成NDT优化失败。

固定描述分箱使用每扫描完整点时间内原始gyro模长的时间加权P90，单位rad/s，不参与新增算法阈值：

**关系并不单调，不能证明快转导致扇区稀疏。** 场景、视场与时间聚类混杂。另一方面，原运动排名前100及前1000窗口全部被结构门排除；这些滚动窗口高度重叠，不是1000次独立失败。说明筛选对当前高运动候选区域有强烈选择偏差，而非仅选中最终窗口后即可忽略。

## 方法适用性判定

固定16扇区可作为**有限适用范围的冻结工程基线**保留，但不宜不加修订地作为整个loop2高运动恢复研究的通用主方案。证据是69.39%帧与96.28%原合法窗口不能评价，且高运动候选区域遭强烈筛除。当前合法窗口的工程通过不能抵消此适用性缺口；也不能据此否定尚未验证的所有结构留出方法。
