## 11项排序及缺失

- gaussian：风险值 = −原Gaussian，越低分风险越高；不是正确性概率，不做跨帧校准。
- native_inlier：风险值 = −原Inlier，越低风险越高；保留地图原点25m裁剪语义。
- nn_fitness_m2：风险值 = 原全点NN Fitness，越高风险越高。
- d_t_m、d_R_deg：风险值 = R11原平移范数、SO(3)相对角度，越大越高。
- h1/h3/h5_t_ratio、h1/h3/h5_R_ratio：风险值 = 当前修正/前h次修正中位数，与R11相同，越大越高。不是累计均值、不是rate_ratio，也不挑一个最有利h隐藏其余。

仅方向翻号，不归一化、拟合、加权或合成评分。原始缺失/非有限、零分母或历史不足保持空值并记录原因，不填epsilon。对全部120帧和每个固定窗口分别排序，先风险值降序，完全同分按raw升序，第一名风险最高。排名CSV保留无值行且rank/Top为空，不能删原样本。

Top10%=ceil(n_valid/10)，缺失不在n_valid中；同分也按raw规则截取固定个数，不扩大集合。分数相同的统计AUROC用半胜、Spearman用平均秩，raw只用于操作性排名/Top，不制造额外区分能力。

## 封存后标签（仅离线）

沿用R10官方T_M_L参考与原插值：位置线性、姿态SLERP，bracket≤150ms且最近端点≤50ms，无SE(3)或时间拟合。分别保存预测/NDT参考误差及Δe_t、Δe_R。以下边界精确含等号，不加epsilon：

H=(Δe_t≥.10m 或 Δe_R≥2°)；B=(Δe_t≤−.10m 或 Δe_R≤−2°)。
- H且B：MIXED_MATERIAL；
- 仅H：MATERIAL_HARM；
- 仅B：MATERIAL_BENEFIT；
- 否则SMALL_OR_AMBIGUOUS。

每维增加/减少量以及H/B布尔量保留；MIXED不偷偷并入二分类正/负类。没有合法参考则REFERENCE_UNAVAILABLE，保持输出行但不加入参考评价分母。

预测分组：位置≤.5m且旋转≤5°为NOT_LOST，否则ALREADY_LOST，仅离线分组，不是可在线访问的预测可信度。报告ALL/NOT_LOST/ALREADY_LOST，在GLOBAL及D/E/F/G均出指标，包括空组。

分组排名只能对**已封存的顺序做限制**，不重新计算风险值、不改变方向。GT分组不可能在封存前确定，必须标明这些Top是封存后离线子集分析，不是新的在线策略。无法据分组排名声称在线已知预测是否失锁。

## 评价定义

每特征/范围/预测组的可评价集合V = 该范围、该组、有效特征且合法参考；n=|V|。报告范围总数、特征缺失、参考缺失、V中四类数量。K=ceil(n/10)。

Top有害比例 = Top中MATERIAL_HARM数/K；Top有益比例 = Top中MATERIAL_BENEFIT数/K；Recall = Top有害数/V有害数。基准有害比例 = V有害数/n；lift = Top有害比例/基准有害比例。无分母则NR，并给原因。Top中mixed数也单独保留。

AUROC仅比较V中的MATERIAL_HARM(正类)与MATERIAL_BENEFIT(负类)，用P(risk_H>risk_B)+.5P(相等)；任一类为空则NR，不能填.5或1。可计算不等于样本量有资格。

Spearman分别计算风险值与连续Δe_t、Δe_R，覆盖V全部四类。等价于高风险数值平均秩与误差变化平均秩的相关系数，正号表示高风险伴随更大误差增加；不是用“1=最高风险”的反向序号导致符号颠倒。常量或n<2则NR，不计算独立样本显著性p值。

主要总体证据使用GLOBAL/ALL；所有窗口和预测组必须一起报告。充分样本限定每特征集合中H≥10且B≥10。A要求至少一个充分集合同时满足AUROC≥.75、lift≥2、Top有益比例≤.10；若仅窗口/预测子组满足而总体不满足，只报告局部支持并明确混合表现，不偷偷升级总体。若全局没有任何充分样本特征，优先EVALUATION_INSUFFICIENT，不因小样本高AUROC改成支持或不支持；其余按用户B/C区分描述性混合或无支持。A/B/C不能掩盖样本资格不足。
