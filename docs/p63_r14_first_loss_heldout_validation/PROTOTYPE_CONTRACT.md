- **B：空间划分 Source NDT + 原 UKF。** 只在调用原生 NDT `align` 前改为注册子集；map、初始 anchor、IMU 消费顺序、UKF、NDT 代码和参数均沿用 R10。
- **C：B 的离线 shadow 评分。** B 的在线运行完成并封存后，单独程序读取预冻结 Source、B 的初值/终值和 Target，评分验证子集。此程序不能连接 ROS，也不读取参考轨迹；分数不会进入在线节点、UKF、状态、协方差、阈值或候选准入。

## 空间划分的精确定义

划分发生在 R10 原有 0.1 m `pcl::VoxelGrid<PointXYZI>` 之后、NDT 之前。坐标是每帧 `depth_camera_link` 的源点坐标，网格原点为 `(0,0,0)`，立方块边长 `0.5 m`。每个点唯一归入：

\[
(i_x,i_y,i_z)=\left(\left\lfloor x/0.5\right\rfloor,
\left\lfloor y/0.5\right\rfloor,
\left\lfloor z/0.5\right\rfloor\right).
\]

对 signed index 按 C++ 定义转换为 `uint64_t` 后，使用固定常数 `0x5036335231340001` 与 SplitMix64 finalizer 计算块哈希；三个轴哈希分别循环移位 0、21、42 bit 后异或再混合。哈希最低位为 0 的整块只进入注册集，为 1 的整块只进入验证集。所有常量、负坐标 `floor` 规则、点序遍历和哈希均固定；没有随机种子、帧内重排或参数搜索。完整实现随源码提交。

验证点没有被传入 NDT `computeTransformation`，不进入梯度、Hessian、迭代终止、候选搜索或在线状态更新。每帧必须记录原始预处理点数、注册/验证点数、非空空间块数和两组 XYZ 哈希；两子集并集必须等于完整 Source，交集必须为空。

## C 的后验几何评分

对每帧只比较两个已封存候选：传入原生 NDT 的初始矩阵 `T_map_sensor_prior` 与原生 NDT 终值 `T_map_sensor_ndt`。每个验证点分别经两个矩阵变换到地图系，以同一个冻结 Target KD-tree 查最近邻，记录平方距离分布和支持点数量。没有最大距离截断或根据参考误差选出的门限。

为了避免点数多的单一空间区域支配总分，将验证点按同一 `0.5 m` 立方块分组，先算每块最近邻平方距离中位数，再对块中位数取中位数，作为帧级描述分数。逐点和逐块分布均保存。这里不使用 bootstrap，也不把空间块独立性作为统计假设。

仅为离线描述而生成 `PREFER_NDT`、`PREFER_PRIOR` 或 `AMBIGUOUS`：共同非空验证块少于 2、块间偏好符号冲突或帧级分数相同则记 `AMBIGUOUS`；所有共同块严格同向才记对应偏好。该分类没有在线执行路径，也不作为可部署准入规则。分数差值、块间一致性、点数覆盖与完整分布同时报告，不能只展示分类。

## 反例开发与验证隔离

固定开发反例/对照帧：raw150、raw224、raw309、raw314、raw485、raw515。raw309/raw515 是历史有害修正，raw314 是大幅有益修正，raw150/raw485 保留有益或多维折衷，raw224 是孤立高姿态误差。除这些帧外的合法参考帧预先作为 heldout 评价集；不据这些帧调整空间块边长、哈希、评分、阈值或规则。评分文件和 SHA 必须先封存，再运行只读评价脚本打开 R10 参考轨迹。

P63-R10 的已发表归档已暴露部分固定反例结果，故这不是对研究者完全盲化的外部数据集。heldout 的保护范围是未参与本原型规则/常量选择的帧，不宣称研究者此前从未接触过整个数据集。

## 结果比较、停止条件与解释边界

1. A/B 用同一 R10 地图、时间戳、IMU、初始化和参考插值合同，比较完整 UKF 轨迹；另报预注册稳定区间 raw5–223、恢复后 raw316–514、失锁后 raw515–2379，失败帧不删除。
2. A/B 的轨迹指标使用 R10 地图锚定离线 GICP+IMU 参考，称“参考相对误差”，不称独立真值。
3. B/C 对 raw150、224、309、314、485、515 和 heldout 帧报告：预测/终值参考误差变化、heldout 两候选几何分数、AMBIGUOUS 率、heldout 分数偏好与参考误差方向的一致性。
4. 如果 heldout 分数在 raw309/raw515 不能比对照更好地指出有害修正，或会把 raw314 等有益修正指向错误一侧，则原型判 `FAIL`，不调阈值继续搜索。
5. 即使验证分数与参考误差一致，也只证明这个固定数据上的 shadow 判别信号；不证明独立真值、在线安全性、长序列失锁恢复或适用于其他地图。

运行期间分数不影响 UKF，因此本轮不能声称“阻止了失锁”或“实现重新定位”。是否进入状态更新前的准入实验须另行决策。
