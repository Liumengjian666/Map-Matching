# 候选判断与科学边界

HDL_CANDIDATE_PASS成立的范围：同一冻结外部PCD、同一固定人工起点，原始MID360首400扫描在原NDT_OMP＋无IMU UKF中连续运行；原生收敛、有限值及预注册几何筛选400/400，target未变，没有预注册连续失配／跳变。可把它提交总控作为下一阶段候选底座，而非已验收完整科研系统。

没有证明：真实ATE/RPE、地图物理标定、GT独立性、长期漂移、退化恢复、未知初值重定位、IMU融合或SCI创新。Native matching_error是指定inlier的平均平方距离，inlier_fraction还有map-origin25m裁点；all-point NN fitness是另一个有量纲m²指标。三者都不是位姿误差。converged可含作者迭代终止判据，有限且有大量邻近点仍可能是错分支。

我们没有将旧同系轨迹当GT，没有读取后续GT选初值，也没有为了得到好成绩换窗口／线程数／邻域／voxel／参数。R1/R2负结果继续保留；不同框架、无IMU与有IMU的差异同时存在，不将本轮成功单独归因为某项创新或宣称修复了所有旧问题。

200MiB进程筛选通过；完整callback P95105.995ms未通过100ms筛选。全链路实际墙钟处理约4.53扫描/s，包含离线输入／记录／GUI，不能声称10Hz部署通过。仪表本身开销明示，不用推测的去开销结果美化性能。

正式运行的live GUI截图只显示Noetic提示，后续通过GUI-only修正及封存数据预览验证显示配置。没有把预览当第二条新定位结果，也没有借预览重跑任何优化。最终live入口的GUI修正未再跑400帧。
