## 4. 指标与预算

- 每帧候选/物理代表数，所有对的地图共同覆盖、`|W_jk|`、见证块数、UNKNOWN/稀疏化丢失情况。
- 每对旧NN差、新量程差、`D_jk^r`、是否弃权及原因；候选位姿差；同证据不能重复计独立样本。
- 任何条件偏好与原正式资格分列；**错误接纳率、正确恢复率、ATE/RPE全部NOT_EVALUABLE**。
- 一次性视图构建、逐候选投影、验证和总计Mean/P95/Max、峰值RSS；5连续帧的分位数仅描述，不给统计泛化结论。
- 最多5真实事件、15冻结候选、每事件3个代表、总原生align=0、ROS回放=0、UKF更新=0、外部数据下载=0。不得增加另一个时间段寻找见证。
- 渲染上限每事件196608投影，全部最多983040；这是上限运算预算，不是已测耗时。目标额外验证P95≤10ms、Max≤25ms、额外RSS≤8MiB。独立评分进程加载原图的RSS与未来HDL内增量内存分开报告。

## 5. 成功、反驳和停止

1. **资格成功而非精度成功**：至少2/5事件存在两个物理不同候选，满足4块/8见证要求，能输出有限、可复现的量程证据，资源不超界。只能记`PROXY_IDENTIFIABILITY_OBSERVED`。
2. 若全部没有足够见证：`PROXY_NOT_EVALUABLE_ON_FROZEN_INPUTS`，说明当前输入无法检验此机制；停止，不增加候选、改bin或找第6帧。不能把不可评价包装成检测通过。
3. 若与旧NN完全相同、没有新增可区分信息：`NO_ADDITIONAL_PROXY_SIGNAL`，不继续投入此版本。
4. 若UNKNOWN/地图孔洞/动态点主导、数值或输入身份错误、资源超限：记录具体失败并停止。不得简单降低计数和幅度要求制造偏好。
5. 即使代理成功，仍无法证明新方法偏好的位姿更正确。不得进入在线准入或宣称论文核心创新；须由总控另行决定是否具备合法参考下的固定单模块确认条件。

未来正确性确认的可证伪目标仅作需求说明，不是本轮/下轮自动扩展：在同候选池、相同弃权覆盖率下，相对旧验证确实减少错误偏好且不增加正常副作用；若失败应撤回该方向。需要先有未按方法结果挑选的、参考来源明确的实例。不能用目前NC条件性参考或loop2旧轨迹冒充独立物理真值。
