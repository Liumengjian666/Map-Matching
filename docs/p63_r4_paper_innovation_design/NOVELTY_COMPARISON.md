## 2. 最接近且不能省略的先例

[RegScorer: Learning to select the best transformation of point cloud registration，ISPRS 2026，DOI 10.1016/j.isprsjprs.2026.01.034](https://www.sciencedirect.com/science/article/pii/S0924271626000420)，以及[作者代码说明](https://github.com/WHU-USI3DV/RegScorer)。本轮核对出版方可见摘要/引言及作者README；完整方法与网络细节未核验。其问题就是对称、重复、低重叠时传统IR/MSE/CD可能选错，方法联合空间与特征关系评价候选。因此“低残差但错配＋增加候选评分”不是新问题。A只能尝试一种不用训练网络的、观测等价时明确不作判断的轻量验证机制；不用学习或更换为NDT本身都不足以证明新颖。

量程可见性检验也不是新发现。例如作者原文[Huber与Hebert，Fully Automatic Registration of Multiple 3D Data Sets](https://www.ri.cmu.edu/pub_files/pub3/huber_daniel_f_2001_1/huber_daniel_f_2001_1.pdf)已有visibility consistency。本轮仅用它排除首创说法，没有重做其系统或声称完成全部经典方法查重。

## 4. 最多两个方向的取舍

|标准|A：候选对可辨识性与留出量程验证|B：退化事件触发有限恢复|
|---|---|---|
|潜在差异|候选之间哪些观测能区分，而非单候选曲率；尚非新颖性证明|泛称风险触发/弱方向/多初值与已有论文及我方旧实现高度重合|
|数学依据|相同预测观测不能区分位姿；非重复见证可能提供增量。只是必要条件|没有新增且独立成立的触发/预算原理|
|可证伪|无见证、验证偏好不可靠、正常误拒或资源过高均会否定当前设计|继续改触发容易变成新一轮开发集门限试错|
|HDL接口|align后、任何UKF/last_observation写入前；先只读Shadow|需新增生成或在线门控，本轮没有证据支持|
|资源|投影O(KM)，低额外状态量；时间未测，不能预称轻量|完整align成本较高且已有资源负例|
|SCI价值|若能在合法参考下优于相同候选池的旧验证并保持安全，才可能成立|目前不值得作为新的主要方法|

设计焦点只留A，B不进入开发。**正式结论：NOVELTY_GAP_UNRESOLVED**。A比旧R9究竟多出可重复的安全收益、与近期/经典验证的最小差异、以及“低残差高inlier但错”的合格实验实例均未闭合。没有用“换了一个名字/几何量”代替这些证据。

## 5. 当前证据缺口

1. loop2没有独立GT；已执行R4以低inlier停止，不是目标盲点的直接证据。
2. R19有稳定分离终值，但已知有害分支的普通质量也异常；不能拿它证明普通质量失效。NC参考为地图配准生成，坐标解释又有未认证限制。
3. R13有真正未参加Training align的点和冻结候选，但无正确性标签且旧正式准入全部失败；仅适合验证新量是否可计算/有辨识信息。
4. AGV论文方法全文、RegScorer完整方法对应部分尚未排除重合。若后续发现同信息、同判别/弃权机制，撤回A的新颖性主张，不改名称继续。
