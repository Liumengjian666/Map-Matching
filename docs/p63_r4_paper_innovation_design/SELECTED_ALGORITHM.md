# 单一焦点A：候选对可辨识性限定的留出量程验证

登记ID拟为`INN-015`，状态`PROPOSED`。这是待审研究设计，**未正式选定为已具合理新颖性证据的论文算法**；本轮正式结论仍为`NOVELTY_GAP_UNRESOLVED`。不设计B的另一套触发/候选生成器，不开发代码。

## 1. 科学问题与最小差异

相同扫描的两个不同NDT终值都能贴近重复表面时，平均NN距离可能掩盖少数能区分位置的结构。我们问：先由地图与候选姿态确定“候选预测不同观测”的区域，再以未参加优化的量程验证，能否比同候选池上的旧NN块损失更安全地判断偏好？

差异仅是**候选可区分区域＋量程证据**。分块、留出、可见性检验、稳健损失、弃权和预算均是已有技术。换成量程或CPU实现不自动构成创新。若此设计只是一种已有visibility consistency的应用，或没有相对R9的实际增量，应停止。

## 2. 变量和信息资格

- `T_A_B`把B点变换到A。`M`为冻结先验地图，`L`为LiDAR；`T_j=T_map_lidar,j`是原生NDT候选，`T_P`是匹配前因果预测。
- 优化点`S_tr`、验证点`S_v`、结构块ID必须在候选生成前固定且互不重叠。验证值不参与align、种子排序、候选生成或参数选择。
- 首个计划只复用R13已冻结的Training/Validation分离，不重新做Source。其验证只是**优化外**，并非独立传感器/统计独立样本；静态地图还来自同一loop2记录。
- R3/R4 Full NDT用过的点不能事后叫独立留出。若以后接入HDL，需另立源点划分合同，并以相同Training-only matcher作单模块对照；Full结果只作额外上下文，不能把换Source的影响归给验证器。
- `T_P`只记录`Log(T_P^-1 T_j)`差异，不作为额外独立正确性证书。当前HDL关闭IMU，UKF历史受先前NDT影响，没有经过认证的独立运动先验可用。

输出为候选间证据矩阵、可辨识见证数量、`PROXY_PREFERENCE`、`ABSTAIN_UNIDENTIFIABLE`或`NOT_EVALUABLE`。它不输出“候选正确”的概率，不继承converged作为认证，也不在首个试验中改变UKF。

## 3. 地图投影与可辨识见证

以下常量是**下一轮待批草案**，本轮未生成缓存或运行评分；不允许看结果后调整。NDT全部原参数不变。

为限制验证开销，拟从原地图建立一次只读渲染视图`M_v`：0.50m体素质心；若超过65536点，按固定整数体素键的确定性hash及键字典序取前65536。这不替换NDT target，不改原PCD；需另存原图/派生视图身份和点数。它可能删掉稀少的区分结构，这是设计的明确失败风险。

球面栅格固定64个方位bin×8个俯仰bin，分别覆盖`[-π,π)`、`[-π/2,π/2]`，端点规则固定。记`π_s`为此投影，候选j的地图投影量程为：

\[
y_{jm}=T_j^{-1}m,\qquad
R_a^j=\min\{\|y_{jm}\|:\pi_s(y_{jm})=a,\ 0.5\leq\|y_{jm}\|\leq25\},\quad m\in M_v.\tag{1}
\]

这里只是点地图的最近投影统计，**不是经认证的传感器前向模型**。空bin为UNKNOWN，不把没有地图点解释为自由空间；不从不完整PCD推断完整遮挡或实体边界。25m相对每个候选传感器中心定义，与HDL原生map-origin裁剪不同，也不改变其原生诊断。

`r_a`由`S_v`在同一bin的最近量程产生。一个bin至少有2个验证点、每个候选至少3个渲染点，才可比较。计数资格对全部候选用同一规则，不依损失正负选择。候选j/k的地图侧见证为：

\[
W_{jk}=\{a:\text{地图投影对二者均有效},\ |R_a^j-R_a^k|>0.50\text{m}\}.\tag{2}
\]

先由地图和候选生成`W_jk`，再读取验证量程。记录`|W_jk|`及其占共同有效bin的比例；无见证不意味着机器人没动，而是在此粗化观测模型中无法区分。实际可评价集合还要求验证计数有效。

## 4. 成对证据与弃权

用固定0.50m量程归一化和截断损失，不宣称这是物理噪声标准差：

\[
\rho(e)=\min\{(e/0.50\text{m})^2,1\},\quad
d_a^{jk}=\rho(r_a-R_a^k)-\rho(r_a-R_a^j).\tag{3}
\]

正值支持j。沿用R13原验证结构块，块内只平均共同可评价见证；一个块至少2个见证bin才计入`B_jk`。要求至少4块、总计至少8个见证bin，否则`NOT_EVALUABLE`。不重新挑块争取有利结果。

\[
\delta_b^{jk}=\operatorname{mean}_{a\in W_{jk}\cap b} d_a^{jk},\quad
D_{jk}^{r}=\min_{w\in\mathcal W_B}\sum_{b\in B_{jk}}w_b\delta_b^{jk},\tag{4}
\]
\[
\mathcal W_B=\{w\geq0:\sum_b w_b=1,\ w_b\leq2/|B_{jk}|\}.\tag{5}
\]

式4/5复用R9已有capped-weight稳健成对思想，**不是新数学公式**，也不是概率置信下界。相邻bin/同一表面相关，不能按点数宣称统计显著或独立样本。

同一既定去重规则（0.10m/1°）下，只有至少两个物理不同候选，且j对所有其他代表均可评价、`D_jk^r>0.02`时，才记录该帧`PROXY_PREFERENCE(j)`。否则弃权；不以不存在对手的空条件认证单候选，不把符号优势或相对Score改善直接作为正确性。0.02沿用旧研究幅度门，仅用于代理对照，没有新传感器校准含义。

原生资格、旧正式准入及新代理证据分开记录。首轮R13各候选原有5°准入失败不被绕过；最终正式接纳仍维持历史0次，不把新分数伪装成恢复。

## 5. 数学边界和可证伪假设

若两个候选在全部可见观测中预测相同分布，并且先验相同，只使用这些输入的判别器无法可靠区分它们。这是普通可辨识性限制，不是本项目原创定理。本设计中若所有`R_a^j=R_a^k`，则`W_jk`为空，必须弃权；不能靠归一化、较多相同点或高inlier制造“证据”。

部分重复但存在真实、稳定且被地图/扫描共同保留的非重复结构时，式2可能集中可区分证据。以下任一情况会使这一假设失效：可区分结构被稀疏化删除、地图孔洞使投影失真、遮挡/动态物体主导见证、Source划分显著改变原生结果、错误候选也复制全部观测。全局体素/hash采样还可能不保持物理重复结构的对称性，**人工制造见证**；不能把缓存采样差异当真实可辨识性。即使`D^r>0.02`也不自动排除这些情况。

有合法参考后才可证伪“更安全”：在同一候选池、相同采样/弃权覆盖率下，错误候选被偏好的次数不下降，或正确候选被系统性弃权，则新证据没有达到目标。当前R13无真值，首轮只能反驳/支持**证据可用性**，不能验证这项正确性主张。
