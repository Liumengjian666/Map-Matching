## 七、拟议算法数学模型

候选位姿 (T_k) 下的预期视图为 (V_k=\Pi(T_k^{-1}M))。以两视图双侧可见体素或面片的法向投影差作为定量证据，用同点复测校准噪声和配准误差，将面片标为共同、判别或未知。把可靠差异映射到当前扫描原始点号，在所有候选共享固定权重的目标 (E_k=\sum_i w_i e_i(T_k)/\sum_i w_i) 下比较。搜索分布与局部曲率分别回答“有几个可能的位置”与“当前位姿附近哪些方向弱”。R1 模型及边界见 [研究计划](RESEARCH_PLAN.md)。

## 八、多候选与差异结构融合可能产生的负向交互

增加候选可能扩大差异掩码并稀释点数预算。遮挡、错位和地图误差可能制造虚假差异，强化错误峰。删共同墙面可能削弱横向和姿态约束。若各候选在某点代价精确相等，删除该点不改变排序，重新归一化仍可能制造分差上升。通过固定候选、同点预算、共享权重、留空间块复核和逐组配对判断。 [机制及消融](RESEARCH_PLAN.md) · [跨模块风险](integration_risk_register.md)
