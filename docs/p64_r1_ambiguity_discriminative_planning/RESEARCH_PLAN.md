# 研究计划与数学模型

正态分布变换（NDT）用局部高斯体素表示地图。激光雷达（LiDAR）提供表面采样，惯性测量单元（IMU）提供运动传播。记 T_k∈SE(3) 为从雷达坐标到固定地图坐标的六自由度刚体变换，P 为具有固定点号的当前扫描。

1. **候选可达性**。围绕初值进行有界扰动。Park 分支固定高度、横滚和俯仰，搜索水平平移及偏航。对照使用原始 NDT 位姿、IMU 预测和局部弱方向。在尺度统一的 Hessian（二阶曲率矩阵）中提取弱方向，独立峰由离散剖面确定。
2. **可观测性**。候选预期可见集合 V_k=Π(T_k⁻¹M)，Π 采用相同视场、距离、采样、首回波近似、地图覆盖及可见规则。禁止无约束的迭代最近点（ICP）重对齐。以固定法向 n 比较候选两侧的局部投影均值 d=nᵀ(μ_A−μ_B)，方差 v=nᵀ(C_AA+C_BB−C_AB−C_BA)n+v_floor。C 表示局部均值误差及候选扰动传播，体素内点分散度不能直接当作均值误差。缺少相关项时使用保守上界与同地点重复校准。置信区间落入等效带才记 COMMON（共同），离开等效带且支持可靠才记 DISCRIMINATIVE（判别），其余记 UNKNOWN（未知）。
3. **固定候选判别**。由候选地图对称构造掩码，映射回当前帧原始点号。对所有候选使用相同点和权重，E_k=Σ_i w_i e_i(T_k)/Σ_i w_i。主成本用原生逐点奖励取负，缺联给零奖励并单独报告缺联率。G7 的共同、判别、未知权重分别为 0.25、1、0.5，每空间格限额。零总权重弃权。离线评价中 A 正确时 Δ_i=e_i(T_B)−e_i(T_A)，保存每空间块的效应与符号。加权和分母须跨候选固定，禁止对每个候选单独去掉缺联点。
4. **未来精修**。R5 验证固定权重的 E(T)=Σ_i w_i e_i(T) 是否降低真实位姿误差。R6 在选中模式的信赖域（限定优化搜索区域）恢复全部几何约束。R7 用未参与选点的空间块或后续帧确认。每帧最终最多一次地图更新，必要时按方向降权、拒绝或短时惯性传播。

精确共同点的 Δ_i 为零。删除它们保持每一对候选的总差值符号。归一化分母改变即可产生更大的分差，须结合排序与误差判断。潜在收益来自减小相关点、系统偏差及错误关联的权重，或提升粗地图压平的细节。已有观测重组织不会增加物理观测。在正确似然已充分建模时，删点无法增加理论信息量。

## 负向交互与定位实验

| 交互 | 可观察后果 | 隔离方法 |
|---|---|---|
| 增加候选扩大差异区域并集 | 预算被无关片区占用 | 固定候选，报告 K=2/3/5、掩码大小及候选置换 |
| 错位、遮挡或动态物体强化错误候选 | G5/G6 分差放大，正确转错误增加 | 共可见性对照、遮挡压力、留块及候选对调 |
| 分辨率吞没微小差异 | R3 真实几何存在，R4 排序无变化 | 固定候选和点，分别构建 1.0/0.5 m 地图并核对逐点贡献 |
| 同一扫描的噪声用于发现和确认 | 当帧优胜，邻帧反转 | 冻结地图选点，使用独立扫描和留块复核 |
| 削弱共同几何 | 判别改善但横向或姿态约束退化 | 对照有界精修、完整点精修和方向约束 |
| 正确峰缺失且错误峰得到支持 | 主动强化错配 | 先报告可达率，再报告有正确候选时的排序和全样本净收益 |

## 后续阶段门槛与论文证据

| 阶段 | 实验对照、停止条件与论文角色 |
|---|---|
| R5 | 比较固定候选无精修、完整点、差异点、软权重及等预算多初值。评分改善但真实误差未降即停，检验主动恢复 |
| R6 | 对照六自由度、弱方向、完整点与有界完整优化。平移旋转尺度用 5 m 等效长度并做 2/10 m 敏感性检查。频繁跳回错误模式或可信方向明显退化即停 |
| R7 | 无门控、仅降权、仅拒绝与独立区域验真。比较风险—覆盖率、有益误拒和恢复时长。过量拒绝造成收益即停 |
| R8 | R2–R7 通过才做在线集成。约 10 Hz 输入下测队列、丢帧、均值、第95百分位和峰值、内存、CPU。持续积压即停平台部署 |
| R9 | 固定图和初始化，四格因素交互、固定候选直接对照和模块消融。区段统计并保留失锁覆盖。跨样本收益消失要收缩结论 |
| R10 | 公开验证通过且获得实物授权再部署独立 ROS1（机器人操作系统）工程。同硬件、功耗与线程设置做端到端验收 |

R5–R10 数值阈值在各阶段运行前结合前一阶段结果冻结。R2–R4 使用本轮 [实验协议](experimental_protocol.md)。
