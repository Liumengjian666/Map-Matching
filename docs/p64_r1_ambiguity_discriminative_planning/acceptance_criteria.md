# 验收与停止

| 阶段 | 初始门槛 | 停止与诊断 |
|---|---|---|
| R1 | Park 核心机制、成熟差异检测、真实细结构及稳定特征原文、历史逐帧复核、至少一套初步实验数据、固定条件与本地归档 | 基本资产成立。正式歧义验证需先闭合报告所列准备项 |
| R2 | 开发集正确候选覆盖率 ≥90%，适配组比同预算最佳直接基线下降不超过 2 个百分点。分中心、SINGLE/MULTI/FLAT 与测试分母报告区段置信区间。进入 R3 还需 ≥3 个物理独立区段，每段至少 5 个正确候选可达的多峰帧 | 优先查搜索边界、平面遗漏、量化及候选抑制。允许一轮单因素开发诊断，仍缺跨区段多峰则停止 R3 |
| R3 | 同点重复假差异 ≤10%，双侧可比较范围 ≥50%，可靠差异跨帧观测率 ≥70%。≥3 个独立区段有双侧支持，异候选对照相对同点噪声的区段中位差为正并报告区间 | 首查密度、遮挡、地图误差和候选扰动。仅一次依据重复扫描校准门槛，验证方向反转则停止 |
| R4 | 正确候选可达多峰帧上 G7 相对 G0 ≥10 个百分点，优于同预算 G1/G2，验证效应同方向，正常误选率增加 ≤2 个百分点。区间含零则记证据不足 | G8 无改善查信息上限。G8 改善而 G6/G7 不改善查选点与可靠性。单区域支配、缺失严重或正常误伤则暂停 R5 |

直接迁移、适配与最终集成的证据沿 [适配矩阵](adaptation_matrix.csv) 逐项封存。首个劣化接口按 [跨模块风险](integration_risk_register.md) 配对回退。
