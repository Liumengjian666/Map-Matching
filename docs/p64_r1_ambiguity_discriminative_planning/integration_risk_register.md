# 跨模块负向交互风险

所有风险均为待检验。已有 P63 与两探针历史只提供对照和反例。

| 首次可能发生的接口 | 负向交互 | 检测与单步回退 | 判停 |
|---|---|---|---|
| 传感器→A | 预测协方差过窄或坐标表示有误，删掉正确峰 | 固定输入，恢复 Park/等预算六维网格，检查中心、边缘、候选漏失和现场初始化 | 主可达率 <90% 或适配下降 >2 个百分点 |
| A→B | 候选平移/旋转误差在远距离产生微小虚假差 | 锁定候选，比较无传播/有传播与 ±0.05 m、±1° 变换。检查同点对照 | 假差 >10% 或双边支持 <50% |
| B→C | 点密和单向遮挡导致未知区被当判别区 | 用同图、同预算切回原八叉树和 M3C2，再逐个检验共可见、密度和误差传播 | 改进若依赖弃权且支持不足，则该版未通过 |
| C→D | 稳定但无判别力的大片静态面，或一个动态块决定所有排名 | 同集合比较 G5/G6/G7，逐区域留块并输出配对四格 | 误伤超过门槛或少量高度相关证据主导即停止 |
| D 排序→重匹配 | 相同点筛选改变能量面和关联，选对峰后优化反而错误 | 固定排序与初值，重匹配前后比实际误差和模式，回退到仅评分 | 实际位姿未改善即停止深入融合 |
| D 重匹配→全几何精修 | 原始共同几何将解拉回错峰，或差异几何束缚方向不足 | 比全几何无界、有界、多子空间版本和完全删除对照 | 模式跳转、有效秩下降或轴误差明显上升即停止 |
| D→E | 重复评分产生虚假高置信，遗留多峰压成过小协方差 | 支持独立留块，重算概率剖面与稳健协方差，并验证新息分布及覆盖率 | 有害接纳偏高，有益误拒或过量拒绝导致表面收益即停止 |
| E→闭环 | 错误融合产生长期失锁，或额外计算积压破坏时序 | 回退一次更新规则、跟踪失锁及恢复时间，测分阶段耗时和队列 | 连续性能下降或不能持续处理目标输入，暂停系统验收 |

首个负效应的定位顺序为 I0→I6。先在固定候选池、同目标图、同扫描和预先上限下做成对诊断，再用各组自己的因果轨迹检验闭环。任一前序失效的场景继续纳入总覆盖和失败报告，不进入后续选择能力的条件分母。
