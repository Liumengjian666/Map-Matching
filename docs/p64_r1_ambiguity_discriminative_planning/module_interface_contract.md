# 跨模块接口契约

这是 R1 的设计合同。后续实现以离线序列化工件测试，各阶段验收后才用于在线定位。

## 公共时空和身份

- 固定采用 T_AB 将 B 表示的坐标变换到 A。M 为先验图，L 为一帧去畸变参考时刻的传感器坐标，I 为惯性器件坐标。T_LI 是固定外参。地图裁切和可见图使用 T_ML⁻¹ 作用于世界点。
- 位姿用右扰动 T′=T·Exp(ξ^)（在位姿自身坐标中加小量）。ξ=(δρ,δθ)，前三分量为米，后三分量为弧度。协方差使用同一切空间且记录线性化中心。跨中心用相应伴随矩阵或 Log 的雅可比重表达。信息性排序使用 q=(δρ,ℓδθ)，ℓ=5 m，数值灵敏度 2、10 m。计分精度阈值中的角度可用度呈现。
- 时间采用整型纳秒的同一传感器时钟，记录每帧开始、结束、参考时刻和姿态有效时刻。因果模块只读取适用时刻以前已到达的扫描和 IMU。不同数据集的 header、bag record 和参考时钟不可混用。无点内时间的深度快照按瞬时模型处理。外参版本、去畸变方式、源点单位和原始点索引必须保留。
- 所有结构携带 dataset_id、frame_id、t_ref_ns、scan_sha、map_sha、config_sha、明确的坐标和算法版本。NDT 地图分辨率、逐点采样和可见格分辨率分别记录。原始点号穿过所有采样方法，排序阶段可复查同点同权。
- 评分带 score_type、direction、单位、分母和缺联策略。Park likelihood（固定姿态观测似然）、native gaussian（原生累加奖励）、nearest-neighbor fitness（最近邻平方误差）、离散权重、各轴不确定性使用不同字段。除非通过校准验证，权重及分差不赋正确性概率。

| 模块与输入 | 输出与必要字段 | 有效性、复杂度及失败分支 |
|---|---|---|
| A 搜索。Scan 点列表及点号、Map 体素、高斯版本、T_pred、Σ_pred、T_ndt、搜索维度和预算 | Candidates：每项 id、T_ML、搜索中心、模式连通域、峰值、鞍点、边界、支持率与局部协方差/扰动样本。总体 SINGLE_MODE、FLAT、MULTI_MODE、NO_VALID_MODE | 评分 O(K_g N h)，K_g 为评分姿态数，N 为源点数，h 为每点体素访问上限。只有独立近峰进入 B。正向协方差未知时打标，先用预设边界。无有效模式、边界漏峰或大时间缺口走原流程或退化回退 |
| B 几何差。Candidates、带地图采样时间和估计误差字段的固定图、传感器视场、可见性规则 | Views：每候选在假设 L 坐标中的期望点、射线状态、密度与覆盖。RegionDiff：对称候选对、面片 id、差值 m、误差界 m、等效带、有效支持、COMMON/DISCRIMINATIVE/UNKNOWN | 地图查询约 O(K log M + 输出点数)，两两比较约 O(K² B C)，B 为面片数，C 为每面片预算。视图密度、局部误差和姿态扰动共同验证。几何定义不闭合或缺射线/支持就 UNKNOWN |
| C 稳定性。RegionDiff、当前和历史扫描点号、外参、因果对齐及动态标记 | SharedSelection：按 id 排序的当前点号、非负权重、空间块、原证据和支持报告、排序输入封存哈希 | 预计 O(B F n_q)，F 为过去帧数，n_q 为每块查询成本。使用至少多面片邻域与跨帧支持，对候选置换不变。点或独立面片不足则弃权，禁止某候选单独选点 |
| D 排序与局部精修。冻结 Candidates、SharedSelection、统一 NDT Map 与评分器 | CandidateScores：逐点代价、每候选四元数与支撑、加权与未加权分差。Refinement：唯一候选 id、精修 T、收敛及模式边界、尺度化 Hessian、迭代数与资源 | 固定评分 O(K N_s h)，重匹配 O(K I N_s h)，I 为迭代数，N_s 为固定筛选点数。分母一致、有效支持≥50%、候选哈希固定。跳模、数值病态、或全几何复核无支持时回退 |
| E 协方差与状态更新。Refinement、保留的剩余候选、预测不确定性和独立复核 | Observation：有效方向的基 V、残差、校准 R、时延、来源 scan_id、接纳/降权/拒绝。FilterState 通过最多一个地图观测更新 | 正定范围、有效秩、残差和单位检查。求局部采样协方差约 O(K_v N_s h)，加少量固定维矩阵运算。剩余峰、选择偏差或不具备一致性时保留可信子空间或拒绝，短时仅靠因果惯性传播 |

## 接口试验与准入

1. **A→B** 在 ±0.05 m、±1° 量级扰动下检查法向结构差是否保持符号及等效分类。姿态误差上界已超过候选差时该面片保留 UNKNOWN。
2. **B→C** 对同地点同物理区域的重复观测估假差，报告可比较范围、样本量、面片覆盖及同图相关性。可见性由已知视场及可验证射线证据界定。
3. **C→D** 检查所有候选收到字节一致的点号与权重，空间块无单支配，体素特征保留足够，报告共点分母与入点率。点不足可做仅排序或退回普通 NDT。
4. **D→E** 仅传经目标一致性和独立验证的精修结果。协方差需与新的限制、相关性和权重一致。状态更新用同一次观测标识幂等防重复；传播、候选评分、接纳与校正的时间顺序须可重放。
