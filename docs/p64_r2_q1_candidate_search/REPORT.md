## 三、原生 NDT 目标函数及源码证据

NDT_OMP 为多线程正态分布变换。DIRECT7 查中心和六个相邻高斯体素。优化最大化各点各有效体素的奖励和。逐点对多个邻域直接累加。缺联点奖励为零，最终 transformation probability 仍除以全源点数。最近邻 fitness 为另一独立距离统计。Hessian（二阶曲率矩阵）含变换的二阶导数及指数曲率项，在当前关联区间计算。零步长且非 NaN（非法浮点值）时原生可返回收敛，H2379 的零关联、零迭代验证了这种情况。[源码和公式](NDT_NATIVE_OBJECTIVE_ANALYSIS.md)
