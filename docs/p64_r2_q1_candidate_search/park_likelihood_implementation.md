# Park 观测似然固定姿态搜索

**Paper-faithful implementation with documented assumptions**

Park 与 Chung 2024 的 §2.1 pp.2792–2793 给出式 (1)–(5)，§2.2 pp.2793–2794 给出离散位姿概率与协方差式 (6)–(7) 和算法 1。§4.2 p.2796 给出范围、步长及 α。第 2794 页算法 1 下文明确空体素测点用离群概率计入。依据案例的历史 NDT 终值固定搜索中心。查询的是三维先验地图和三维源云，搜索自由度只有水平位置和偏航。 [论文原文](https://onlinelibrary.wiley.com/doi/10.1002/rob.22392)

## 位姿和地图

- 以 T₀=(R₀,t₀) 表示源坐标到地图坐标的历史配准终值。在地图水平面以 T₀ 的航向建立 x、y 轴。对局部平移格 u=(u_x,u_y)，地图系位置为 t=t₀+R_z(yaw₀)(u_x,u_y,0)ᵀ，姿态为 R=R_z(δyaw)R₀。以 ZYX（偏航、俯仰、横滚）角解释时，原有俯仰和横滚固定。角度输入格以度定义、实际变换及协方差计算转为弧度。
- 两个水平方向均在 [−2,2] m 以 0.2 m 步长含两端，偏航在 [−5,5]° 以 1° 步长含两端。共 21×21×11=4,851 个姿态。遍历中每个姿态进行刚体变换和评分，不从格点发起优化。历史中心姿态作为网格中心格，少量验证用局部优化另计预算。
- 使用相同的实体地图点云和统一预处理，独立按 Park 式 (1)–(2) 计算每格样本均值和无偏协方差。h 为按帧冻结的格边长。实现以坐标取整查找点所在格，只用这一格的统计量，即使其他邻格存在。对于网页与 PDF 均未规定的最少点数和近奇异处理，固定采用至少 6 点和最大协方差特征值的 1% 为特征值下限，无法构成有效高斯时只走离群项。格索引按坐标元组查找，杜绝图外线性索引误落入另一格。
- Park 自行拟合的格协方差与相同点云上 NDT_OMP 的格协方差可以不同。原生构建从 I 累加外积并按自身规则进行缩放。本对照比较的是实际原生优化目标与依据论文重建的观测似然。

## 似然与归一化

以 x′=Rx+t、q=(x′−μ)ᵀΣ⁻¹(x′−μ) 表示变换点和马氏距离平方。按式 (3) 的高斯和均匀混合项实现：

    G = (2π)^(-3/2) det(Σ)^(-1/2) exp(−q/2)
    p_i = (1−ρ) G + ρ/h³    有可用的包含体素
    p_i = ρ/h³              空体素或高斯无效
    L_k = sum_i log(p_i)

§2.1 有两种文字表述，先写最小化负对数似然，末句写最小化对数似然。本轮的固定姿态评分方向以式 (5)–(7) 和算法 1 的概率赋权为准，较大似然获得较高权重。论文给出 p₀ 为预期离群比，c₁、c₂ 由概率模型决定，未公开这两个系数及离群比的具体数值。固定假设为 ρ=0.55，作为与原生默认工作的可核对常数。高斯项采用概率密度的体积归一化，均匀密度取 1/h³。公式作为按格定义的评分模型使用。未将高斯截断后按格重新归一化，也不将此模型解释为积分为 1 的全地图连续概率密度。输入点集、地图和所有参数都在参考评价前冻结。

点级先计算高斯项与正的均匀下限之和再取对数，每个扫描点入账一次。冻结参数下指数随马氏距离增大而衰减，衰减下溢时仍保留均匀项。计算全扫描及网格概率时使用对数域和减最大值归一化。式 (5) 的全帧乘积等价于上述**对数求和**，不用分子或有效关联数量把 L_k 变成平均。按式 (6) 用均匀位姿先验，式 (7) 上固定 α=0.001。对于全有限 L_k，离散归一化权重为：

    w_k = exp(α(L_k−max_j L_j)) / sum_j exp(α(L_j−max_j L_j))
    mean = sum_k w_k x_k
    covariance = sum_k w_k (x_k−mean)(x_k−mean)^T

维持正的均匀项使空覆盖姿态仍有有限分值，本轮固定 h=1 m，各格使用双精度计算似然。若全图无覆盖，归一化仍可产生均匀结果，几何有效性需由独立支持统计拒绝。权重在本轮只解释为冻结假设下的**网格相对质量**。温度在统计意义上缓解独立点乘积的过度集中，不能校准定位正确率。按式 (7) 计算搜索维度的方差与相关性时，使用已记录坐标量或等价的局部偏移，针对三维全姿态的未搜索量不能从网格观测直接恢复。Park 文中按平面和偏航方差给 z、滚转及俯仰经验赋值，本轮只分析搜索与局部尺度，不将经验方差接入惯性滤波。

## 与 Native NDT Score 的可比范围

| 对照维度 | Native | Park |
|---|---|---|
| 地图协方差 | 原生协方差先放入单位阵并做原生缩放、规则化 | 同点云独立计算样本协方差，以固定样本数及特征值下限补足工程细节 |
| 查询 | DIRECT7 中心及六个面邻 | 点所在的单个有效格 |
| 拟合项 | 原生常数乘一个指数，逐格累加 | 每格按 det(Σ) 标定的高斯密度 |
| 离群/无覆盖 | 无邻格时奖励为 0 | 按 ρ/h³ 计入离群密度 |
| 全帧 | 各点奖励求和，可另报告除 N 的平均奖励 | 对数似然求和，再独立温度归一化 |
| 优化契约 | 最大化原生奖励，局部精修以此为准 | 当前实验仅固定姿态评分与直方图，由原始 NDT 历史终值定位网格 |

两种函数的排序没有理论上的单调等价关系。原生邻域加和、Park 单格边界切换、局部密度归一化、离群概率以及原生/样本协方差的差异均可造成排序改变。主结果冻结相同姿态集合和输入，分别报告两个目标上的支持、拓扑峰、分差及正确候选排名。对照中发现差异时可归因于这些机制类别。逐因素定量归因须用一次改动一个因素的后续复核，不能依据两条完整评分管线的差值认定单一根因。

## Gate 2 的可核验记录

每帧输出网格键及矩阵、Native 合计及全点平均、Park 对数似然、归一化质量与双评分各自的有效支持。核对三轴全范围、全组合和评分姿态数，底层浮点舍入不得改变网格索引方案。检查温度常量、最大分数配置、累积质量以及扁平或支持不足的格子。查询模型不使用参考位姿、未来测量或姿态正确性标签。本阶段覆盖率及峰距仅在候选产物封存后由离线评价计算。
