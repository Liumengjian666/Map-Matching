# Q2 离线评价与原始证据

评价器先核对 Q2 封存 SHA-256、Q1 复用网格和所有已封存的源点及目标图，之后才加载参考轨迹。标准正确性为平移误差 ≤0.15 m 且旋转测地误差 ≤2°。报告附带 0.10 m/1°、0.20 m/3°、0.50 m/5° 对照。本轮所有 12 帧为开发资格样本，按冻结分组逐帧给出。

- **网格可达**记录参考容差内是否存在任意评价位姿，并另报各评分口径满足 50% 支持率的点，两个字段不可混作最终结果。
- **保留可达**固定原始候选排名输出 Top-1/3/5。C0 的 S0 直接读取 Q1 原表。C1 的边界补槽不替换分数最强者。C2 的相对评分保留及空间抑制可能丢失可达候选，该损失单独登记。
- **精修可达**并列记录所有原生优化终点及其在当前候选政策下的保留资格。仅优化器报告收敛、迭代数大于零且 Native 支持不少于 50% 才计为合格。接受还要求平移漂移 ≤0.35 m、转角漂移 ≤4°，以及当前目标对应的支持率不少于 50%。需要标注 S0 的复用调用和 Q2 新边界调用。
- **最终选择**C0/C1/C2 以各自冻结排序为准。C3 对每个保留的原网格候选，以接受的同索引精修终点替换原位姿，失败和未优化保留原点，再依据同一目标重新排序。Native 与 Park 只复用几何终点，各自目标和支持独立。S0 复用精修中的 Park 终点分数来自 Q1 已归档逐点对数项求和，未重新评分。
- **场景诊断**raw309 图使用实测搜索姿态和离线参考位姿。同一 XY 上的多个偏航采样可能视觉重叠，误差散点图仍保留姿态误差。旋转传播量纲对照采用点距离乘角误差弧度，作为一阶量级，不代表置信区间或结构检测结果。
- **运行指标**新固定网格次数、唯一采样位姿数和提议数分别报告。S0 复用网格的 Q2 网格耗时不反映重新评分成本。普通 NDT 精修、终点复评分、读写和共享预处理按各自字段登记。

Q1 多标签 A–J 原因从历史已封存证据生成。越界标签 A/B 表示参考投影超过字面范围，与联合容差下是否仍可达一起阅读。C 表示固定高度或消去偏航后的残余倾角本身超出容差。F 要求存在正确的边界局部峰，单个正确边缘网格点另计。H 只在从正确种子移动到分离的错误合格终点时成立，小幅跨容差仍然显示于漂移记录。
