第 55 帧前姿态误差已有累积，53/54 帧 NDT 角更新为 2.280°/4.052°。初始状态速度及两种零偏确认为零。第 55 帧预测速度约 (0.218, −0.917, −0.663) m/s，而稠密参考在该段近静止。按官方外参旋转后的比力用离线参考表达于地图轴为 (−0.667, 0.165, 9.645) m/s²，符号及量级与常规比力相符，同时存在水平剩余量。此证据支持预测误差积累可能放大漂移。无法仅由该离线审计分离重力、稠密姿态误差、原生更新和状态耦合。扫描内平移未补偿；该帧近静止和毫米级末回波位移不足以解释约 30° 的单帧跳变。首帧末回波位移代理约 96 mm，不能据第 55 帧断言平移去畸变一直无价值。 [逐帧状态](FIRST_FAILURE_DATA_FLOW.csv) [扫描运动审计](FRONTEND_SCAN_MOTION_AUDIT.csv)

八个不依赖参考的 NDT 初值测试中，第 55 帧同目标最高分终值仍有 43.63° 姿态误差。世界 Z 轴 −10° 初值找到的较接近终值误差 8.76°，但目标值约 1820.15，低于胜出的 1987.21。该结果同时排除了“只要小规模加初值再按原目标取最大即可纠正”的解释。五轮常规点面 ICP 从上一状态出发得到 4.32°，位置误差仍 0.180 m。因果 100 帧的原版 LiDAR-only 支路把位置 RMSE 从 1.091 m 降至 0.359 m，同时把旋转 RMSE 从 30.22° 增至 40.67°。去除 IMU 传播未解决姿态错误。 [固定成熟对照](NATURAL_MATURE_MATCHING_CONTROLS.csv) [因果对照](CAUSAL_WINDOW_SUMMARY.json)

结论边界：首次大姿态跳变产生在 NDT 优化。正确匹配与错误模式之间的原生目标排序、对应与预估误差仍互相影响。没有将本事件解释为走廊纵向平移退化，也没有证实某一前端遗漏是唯一根因。保留原版前端与状态估计作为独立对照。
