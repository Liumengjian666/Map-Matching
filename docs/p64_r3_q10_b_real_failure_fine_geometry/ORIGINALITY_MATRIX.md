# 机制边界

| 模块 | 已有机制 / 来源 | Q10-B 实证及界限 |
|---|---|---|
| HDL / NDT | 原版 NDT 与 UKF | 只读复跑通过。在第 55 帧因果预测后第一次观察到约 30° 的原生优化跳变 |
| X-ICP | 点面对应的局部可定位性 | 保留可见表面和合法点对上的旋转弱性，不能据此证明真值方向不可观 |
| DCReg | 旋转/平移 Schur 分离 | 输出转平移信息及受对应影响的变化，未改其检测公式 |
| LF-GICP 思想 | 物理法向场和方向信息门槛 | 111 个参考姿态诊断没有原先联合门限通过，未重调 |
| 单方向采样 | 既有点面雅可比方向贡献与空间配额配对 | E 在部分段保留弱轴信息，未稳定提高匹配或超过两类公平对照 |
| 普通点面 ICP | 成熟 Huber 局部优化、重新关联 | 开发窗口实测可延续部分姿态恢复，需单列额外约 2.25 s/触发及事后开发选择 |
| 细节与组合 | 成熟环带平面拟合及精确截断平方 | 未出现可认证细结构，G/H/I 未获得有效细节修正。当前没有组合冲突或互补性的证据 |

未提出原创公式，也未把事件触发下的成熟 ICP 组合标作原创机制。现有失败更适合检验旋转错误匹配、原生 NDT 目标排序和有效对应；需要复现独立条件下的收益，才能讨论仍有何缺陷。
