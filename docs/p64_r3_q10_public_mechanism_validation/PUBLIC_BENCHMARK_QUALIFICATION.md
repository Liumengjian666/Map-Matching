# Exp18 公开基准资格

Zhang 等。 [数据入口](https://hilti-challenge.com/dataset-2022) [官方文件树](https://huggingface.co/datasets/Hilti-Research/hilti-slam-challenge-2022/tree/main) [论文](https://arxiv.org/pdf/2208.09825)
