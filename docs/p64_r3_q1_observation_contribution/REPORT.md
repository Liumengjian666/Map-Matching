## 理论与近中性删除

Yin 用有效扫描重访和逐位姿观测保留约束建模。PocoNet 把地图观测价值映射至当前帧高低优先级与单独地面点。EAMC（误差分析地图压缩）对同一地图点在多个虚拟位姿下逐轴计算线面局部敏感性，用偏度和峰度描述该级数据，后用六个一维高斯因子相乘和归一化，贡献为精度加权均值。其原文式 (6) 与式 (12) 的维数/分母问题保留在核查报告。该分数没有候选间对比项。高观测、弱轴信息和多候选排序稳定性分别建模。 [公式对照](LITERATURE_FORMULA_COMPARISON.md) · [EAMC 正文核查](EAMC_ORIGINAL_METHOD_ANALYSIS.md) · [本轮模型](THEORY_CONTRIBUTION_MODEL.md)

删除零分差点不影响固定候选排序。按预设 |Δs|≤0.05 去掉 H307 的 185 点，净删 −0.493，余分差 −30.07；H515 去 759 点，净删 −0.328，余分差 −163.80。正负抵消可使数量较多的近中性点对全帧排序影响很小。几何共同结构还需独立的共视及等效性证据。 [近中性复核](neutral_deletion.csv)
