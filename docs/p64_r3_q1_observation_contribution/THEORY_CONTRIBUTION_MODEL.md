# 竞争位姿下的观测贡献

令 sᵢ(Tₖ) 为 Q1 Scorer::fixed（指定姿态评分）从原生 updateDerivatives 对源点所有有效高斯格获得的累计奖励。无关联奖励为零。对两个固定候选和共享点集 S，取 Δᵢ=sᵢ(T_A)−sᵢ(T_B)，排序以 ΔS=Σᵢ∈S Δᵢ 的符号判定，对任意移除集合 R 有 ΔSₛ₋ᵣ=ΔSₛ−Σᵢ∈R Δᵢ。移除项净和为零则排序不变。近中性点的数量无法决定净和及其符号，这个代数结论也无法判断几何共同结构。

候选解释矩阵 Bₖᵢ 的 MATCHED（候选地图能解释观测）、INCONSISTENT（受支持地图表面与观测冲突）和 UNKNOWN（证据不足）用于标记当前帧假设。rᵢ 是可判条目中的匹配比例，h₂(rᵢ) 是二值解释分歧。二候选都可判时，熵只有 0 或 1；连续深度解释和原生奖励各自独立。Yin 的历史重访观测次数与这组同帧假设比较对应不同样本轴。

右侧位姿扰动用 T Exp(ξ̂)，ξ=(ρ,θ)，q=(ρ,5θ) 以米为单位。R 为源到图旋转，Jᵢ=R[I,−[pᵢ]×/5] 为局部残差雅可比（残差对参数的线性变化矩阵）。正半定信息代理 Hᵢ=Jᵢᵀ[Σᵥ sᵢᵥ Cᵥ⁻¹]Jᵢ 冻结邻域及指数权重，以原生逐体素奖励加权正定逆协方差。原生 Hessian（评分的二阶导数矩阵）还包括变换二阶导、指数的乘积项等，邻域切换时局部代理也失效。此代理用于量化相对几何约束，反演值不代表校准协方差。相对点杠杆为 tr[(H+λI)⁻¹Hᵢ]，其中 λ 取全点最大特征值的 10⁻⁶。测量点自身贡献与移除整组后最弱方向损失分别评价。

绝对固定分差描述原生目标内部的分歧，候选邻域统计测试该分歧对小扰动是否稳健。E2 分母 sqrt(σ_A²+σ_B²+0.05²) 的常数为单点原生奖励单位下的幅值下限。配对扰动差可能相关。均值、分位数、符号翻转及偏度峰度仅作样本描述。若 eᵢ=b+εᵢ 且独立噪声同分布，则 Var(mean eᵢ)=σ_b²+σ_ε²/N。候选扰动可用于探查响应空间聚集，实扫短窗仍混合姿态、采样和建图误差。

候选地图以 Tₖ⁻¹ 变到同一假设雷达表示，无外部重配准。双侧表面差 d=nᵀ(μ_A−μ_B)。共同结构要求有效观测及差异区间落在实用等效尺度内；显著差异须越过最小尺度且当前源点有支持，其余 UNKNOWN。若有可信协方差 P，姿态法向项为 nᵀJPJᵀn；共享地图还需交叉协方差。本轮采用经验扰动和粗糙度带，几何差异需经真实源点固定姿态重评才能证实判别价值。

可删除性是任务与剩余观测集的关系。低判别点可能保留精修约束；高局部信息点可能与其他点冗余；高固定分差可能来自错误关联。候选判别和六自由度优化分别验收。
