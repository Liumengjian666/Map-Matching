# 失败分析和阶段约束

- H307 有历史正误终值，也有双错终值。最近邻和占据差异能修复选定主对，50% 仍不能正确选出完整三候选的第一名。没有 Stage R4 排序或轨迹改善结论。
- H515 正确候选是原始偏航边界种子。历史精修的真实误差从 0.05077 m / 1.12829° 增至 0.19588 m / 4.78710°。几何筛选对未精修主对有益；把该终值纳入压力对后，补齐版 50% GEO0 的分差为 −28.27，只有 1/12 个配对轴扰动正确。仅保留 576 个通过几何门限的点时翻转，预算与几何约束不同。
- H309 为 Park 与 Native 两种归档终值的合法正误对。Hard 实验是 Azure Kinect 深度快照，离散采样模式与 Mid-360 扫描不同。
- 二值观测统计在三个深度快照样本上未产生一条双侧可判的 MATCHED/INCONSISTENT 分歧。当前射线证据规则很保守，地图观测来源及覆盖无法提供真实遮挡标签。UNKNOWN 不进入分歧证据，不能由这次实验否定整个解释矩阵。
- 本轮最直接阻塞是经过扰动和双侧支持控制后法向差异太少，以及真实 Mid-360 真竞争样本缺失。下一轮首先验证候选尺度下的几何可重复性与密度敏感性。应冻结 GEO0、GEO1 和等预算体素基线，再对一个独立短窗口校核双侧可见性及共同结构等效。不能通过放宽门限来保存当前样本的成功。
- 约束 Oracle（参考标记的诊断上限）未运行。无真实遮挡标签、无校准位姿协方差，无线上融合、优化和定位轨迹指标。人工旋转对照未翻转，其余正常环境与误触发尚无统计结论。
