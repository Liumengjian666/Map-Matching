# 负向交互和失败机制

| 观察 | 实验支撑 | 证据边界 |
|---|---|---|
| 只用原生奖励差选点可增强错误偏好 | H307 50% 预算下固定分差 B4 的正确减错误总奖励为 −60.77，邻域均值、标准化和符号稳健版为 −57.78、−79.92、−70.94。完整点云为 −30.56。H515、H309 也未获得纠错 | 原生目标的符号偏差可以在稳定点上持续。对确定性测试的稳定性不能替代正确性 |
| 几何粗指标优于法向显著性 | H307 的最近邻和占据差在主对分别有 1,404 和 734 个支持点。普通法向 66 个，加入姿态与表面误差带后为零。50% GEO0 修复主对排序且对两候选各自十二扰动的 144 个交叉组合均正确 | 最近邻受图密度、采样及局部姿态影响，当前数据无法证明 1,404 个点对应物理结构差异 |
| 扩展候选会稀释成对收益 | H307 50% GEO0 主对正确，第三个冻定位姿重新评分后仍可超过正确候选，三候选正确排名为 2。H515 边界对 50% GEO0 改善，而有精修恶化终值时正确排名为 2 | 成对排序实验用固定目标对构造共享掩码。需要独立验证对多候选的一次统一选择，不能汇总不同点集的原生总分 |
| 正确候选缺失时可稳定偏向错误 | H307 双错对在 50% 下 GEO0 有 11/12 配对扰动偏向第一错误终值，GEO1 有 0/12；两者指向不同错误位置。H515 精修终值加入后，50% 填补版仍选错 | 暂无置信校准或拒绝机制 |
| 局部约束更强可能排序更差 | H307 正确终值 50% 的 B6 保留最弱特征值 59.8%，但分差 −168.63；GEO0 保留 38.7%，能纠正主对。B8 只取 66 个支持点时秩仍为 6，最弱信息只剩 0.705% | 代理量反映局部约束。候选判别掩码应与后续优化掩码分别验证 |
