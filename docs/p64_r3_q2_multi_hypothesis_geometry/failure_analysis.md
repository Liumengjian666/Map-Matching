# 失败与约束

1. H307/M6 50% 具有全候选覆盖收益，但相对于体素仅由第 3 到第 2，原生全点本身已是第 2；正确与最强错误的净分差更差。H515 50% 由全点第 3 到第 2，20% 才出现正确第一。H309 两候选受益，不能替代三候选证据。
2. 观察到 50% 随机稀疏制造伪差异，且会使 H515、H309 主对重新选错。体素标准化和密度上限未消除主对收益，仍无法将差异唯一归因为微小物理结构。用首交回波窗保守地减少证据；地图历史可见性不可追溯。
3. 删除点中存在墙状或水平面状邻域与大量几何 UNKNOWN。没有独立门框、地板、噪声或误关联语义标签。DIRECT7 单邻域反事实只说明奖励累加的数学作用，不能宣布某高斯是错误关联。
4. 法向硬包络把独立两侧确定性扰动取极值并组合，平移、粗糙度与共视门控均削弱 H307 的证据。这是有意保守的确定性外界，未计有校准的联合误差，无法由结果判断应放宽到何种水平。
5. 三次 Mid-360 触发只得到一组弱分离终值。依照预注册不对弱终值运行几何排名验证。装置独立地图已核实，进一步独立困难样本仍是门槛。
