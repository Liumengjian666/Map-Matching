# DIRECT7 固定奖励归因

对一候选一源点，以通过原生高斯有效性检查的 DIRECT7 贡献记录为观测集，包含虽被记录但浮点奖励为零的有效项。令 K 为记录数量，g 为原生高斯奖励，s 为总和，ḡ 为均值，m 为最大，r=s−m。K=0 时全部取零。本轮对同一组邻域应用三个固定姿态聚合算子。R0=s、R1=m、R2=ḡ。R1 使用现有邻域中的最大项，中心体素查询 DIRECT1 从空间规则确定单体素，两者的候选排序可以不同。

用差值乘积恒等式得到

    K_A ḡ_A − K_B ḡ_B
      = ½(ḡ_A+ḡ_B)(K_A−K_B) + ½(K_A+K_B)(ḡ_A−ḡ_B)
      = Q + G
      = (m_A−m_B) + (r_A−r_B).

两套身份逐点验证到 8e−15 的绝对容差，并检查六份历史点贡献与四份新增补导出的全部奖励。Q 表示数量差的代数项，与简单平均关联数差不同。G 表示均值差项。两项仍共享同一个关联生成过程。原生附加奖励 r 的分差可以在最大项不变或更差时主导排名。对于保持点号与共享分母的任意子集，两个分解都能直接求和。

取候选正确相对主对的原生奖励差和最大体素奖励差，在全点或严格等点数体素对照下定义固定奖励尺度交互 I=(B−A)−(D−C)。正 I 表示筛选对原生和的增益大于对最大体素的增益。这个符号不能与候选排序的负向交互直接等同。完整候选最强错误对象可以随掩码更换，须另列完整排名。

源点按 0.50 m 体素做空间归因，几何类别沿用 Q2 冻结的局部主成分拟合。CSV 同时给出有效关联的均值距离、马氏距离、协方差矩阵迹平方根、特征值底、体素点数、相对均值三轴偏移，以及每个邻域平面法向与该点最大项法向的绝对余弦（形状代理，按关联计）。无关联点在这些条件量中的占比通过 K 一并报告。既有体素索引和原始逐体素奖励未改变。均值、法向、稀疏性和分数受同一候选位姿影响，不能用这些统计确定单体素物理关联是否正确。 [原生源码证据](../p64_r2_q1_candidate_search/NDT_NATIVE_OBJECTIVE_ANALYSIS.md) · [逐组归因](reward_quantity_quality_decomposition.csv)
