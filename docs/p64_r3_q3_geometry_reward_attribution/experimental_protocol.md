# Q3 冻结协议

历史主对复核后，仅补导出缺失的 H307_N1739、H515_C3_terminal、O164 的两个候选。其他六候选从 Q2 逐体素文件读取。名义姿态不拟合。所有掩码为冻结点号；先共享评分，后连接历史标签。R0、R1、R2 使用同一 DIRECT7 邻域。K 为有效返回的体素贡献记录数，记录值为零也保留。K=0 时四个奖励量均为零。主分析 50% 预算沿用 P2/M3、P3/M6，另比无全云分母偏差的 P1 对 P2/P3。G2 不补齐的双侧支持；G3–G5 最多 floor(双侧支持/2) 并限制在 50% 全云预算内；另按 0.30 m 体素用 G5 的每块配额随机选择，隔离空间分布与差异排序。随机种子 6400–6409。无参数拟合。

几何尺度控制使用冻结 H307 首候选局部图内最密的真实平面补丁。用固定平面局部基底重采样诊断图，构造无偏移、随机减半、3 cm 网格相位变化、2/5/10 cm 局部法向偏移与全图 2 cm 平移/0.5° 转角。球和门限沿用 Q1。已知标签只用于评价。真实地图库内容不改变。

Mid-360 预注册：在已归档 Omni 长序列的 Protocol A 传感器时间关联日志中，只用原生初值到终值的位姿变化挑选高创新时间锚。离开 Q2 正常短窗；三个窗口最多各 72 实际帧，每个窗口从中心前 32 帧开始，以独立 Diff 地图和该帧扫描沿用 Q2 的参考独立占据相关初始化。未通过该冻结初始化门槛的窗口不运行 Protocol B，也不使用 A 代替。选中心间隔至少 30 s，至少相距 3 m（由历史估计，不用参考）。触发帧为历史上冻结的中心，另在因果窗口锚后 22 帧起按运行中创新阈值 0.20 m 或 4°、关联率低于 0.80、或无效迭代触发。每窗至多四帧，触发间隔至少五帧。沿用 Q1 Native 4851 位姿网格、原峰值提取和最多四次原生拟合。B25 只复用归档终值。竞争至少两个有效分离终值；奖励比达到 0.90 单列强歧义，较弱也允许固定验证。没有合格双候选的触发帧仍做原生有效收敛与离线参考诊断。最多 12 次触发、58,212 网格评估、48 次候选资产拟合、216 帧因果原生跟踪。本阶段拟议二次优化为零。
