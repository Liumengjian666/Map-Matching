# 机制限制与失败

- 最大单体素让完整 H307/H309 正确首选，但仍无法纠正 H515，也不能直接作为优化目标。配合同一几何掩码时，前两帧的首选都会再次变错。H515 与 H307 中最强错误会随掩码改变，需要全候选合同比较。
- H307/H515 仅按空间配额随机抽样即可获得与最近邻排序近似的原生奖励优势，H309 留有可能的小裕量收益但没有附加完整排序收益。三个样本已曝光，不能凭此形成正式总体结论。
- 半密度诊断的 101 个伪差异与 5 cm 位移 0/25 的最近邻检出说明当前几何标签无法直接解释为物理微结构。法向最小对照只能部分修正。
- Mid-360 独立窗口仅有弱竞争，双侧样本支持稀少。B25 的支持掩码只选 34 个实际点，翻转原本正确的首选。回填后正确不能归功于这 34 点。可靠性需要同时约束支持度和空间覆盖。
- 首次 Mid-360 离线结果导出把 NumPy 布尔值与 Python False 做对象身份比较，误使正确减最强错误列留空。仅修复离线标签序列化，再从同一封存排名重建分差；候选、原生奖励、几何掩码和参考使用阶段均未变化。首次报表在 run/pre_margin_fix 保留。
