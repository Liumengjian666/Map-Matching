# P64 事件触发定位框架

目标是在固定先验图的退化及重复结构环境中改善机器狗位置估计。正常扫描维持惯性测量单元（IMU）传播、原生正态分布变换（NDT）配准和一次地图观测更新。有风险的扫描进入有限候选搜索和共享几何验证，再按证据接受、部分更新或仅传播。

## 两条独立的诊断轴

- 局部约束不足：给定一个位姿邻域，局部残差无法稳定约束某些方向。使用统一尺度下的约束矩阵、弱方向及原生支持指标报告。局部弱只意味着该处估计敏感。
- 非局部歧义：两个位置的观测可相似，即使各自局部约束良好。用相对分离、候选评分与独立支持诊断。弱方向搜索不能代替相距较远的候选探索。
- 区分原因与触发器。主动分支由弱信息、低关联、迭代无效、大创新量或有限周期探测触发。周期探测只做预算允许的候选评价，以测原来绕过退化检测的事件。时间与质量状态联合入日志，评估时单列周期探测的代价和漏检率。

## 决策分支

固定地图和源云生成原生结果。若正常且在时限内，提交原生单次观测。触发帧先封存候选集和候选有效性，再获取预期地图视图。几何输出明确区分双侧有证据的共同/差异，以及未知。使用相同点集和权重评分，并保留全点对照。只有通过独立区域和全云复核后，才允许候选获得有界全云精修。精修越界、候选分歧、支持不足与资源超限均进入明确回退；如原生本身仍可信，保留原生结果。如可信方向可证，仅在已验证的融合适配器中投影更新。否则保持惯性传播，统计拒绝长度并等待地图观测恢复。

用已有事实约束默认配置。R3-Q3 在 H307/H309 的全点单体素最大评分恢复正确首选，而与几何掩码叠加后再次失败。H515 的双侧支持和空间配额对照已解释大部分分差。B25 仅凭 34 点反向翻转真实 Mid-360 正常首选，W2_32 只剩 11 点双侧支持。5 cm 几何标签在单平面控制中检出不足。这些检查要求将几何重评分先置于影子模式（记录拟议决定，状态仍走基线），将奖励模型切换、微小描述子及方向融合设为独立可关闭项。低支持不会因体素补齐而获得额外准入证据。

## 成熟模块的组合与后续研究边界

首轮复用原生评分、已有有限候选提取、先验图局部裁剪、最近邻双侧支持、体素空间均衡和局部信息代理。Park 原文概率与 Native 分开记录。退化方向先用轻量观测报告，同时独立复现 X-ICP 或 DCReg 的点面参考输出。M3C2 型小型法向对照与跨帧支持依次作为替换项；完整 DeCOD、FE-LOAM、RegScorer 不进入首轮在线关键路径。系统保留一个可替换融合端口，先确定同一后端的对照，再进行 IKFoM（流形迭代卡尔曼工具箱）单独适配。

交付路线为原始模块资格→离线完整链→独立工作区连续系统→开发数据分析→冻结一至两个创新→独立持出→真实机器狗部署。当前交付为设计和接口冒烟，另行批准后才能进入实现。
