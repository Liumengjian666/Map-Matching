# 公开基线与配对消融协议

所有 A–H 使用同一源点、外参、地图、时间窗口、初始化合法来源与参考规则。需要测量特定模块时，同一套因果后端、去畸变、传感器输入与资源上限同时固定。不同后端另成实验层，不把滤波切换计入模块增益。每次保存地图、配置、代码 SHA，构建/运行命令、硬件、时间配对和原始结果。

| 组 | 实验行为 | 判别贡献 |
|---|---|---|
| A | 原生 NDT + IMU，不接新分支；同 UKF/IKFoM 的 A 分开 | 正常、退化及歧义的原始水平 |
| B | A 加成熟局部退化检测/处理。分别报告只探测及有方向处理。点面原法和 NDT 适配分开 | 局部退化检测及弱方向风险 |
| C | A 加成熟候选搜索与完整点云重评，保留固定候选预算及后端。无 GNSS 时明示 Park 改编 | 候选可达性和全云排序 |
| D | A 加单候选可运行的局部结构显著性/微小结构排序对照，普通体素匹配点数 | 单独几何模块的价值，单候选基线无竞对假设 |
| E | 能通过资格的成熟模块直接组合，使用固定支持和原生奖励，后端匹配 | 首个完整因果组合，创新的必须超越对象 |
| F | E 加被冻结的一至两个创新机制 | 全部收益与新失败 |
| G | F 取消事件触发，链路和每次预算一致，所有可处理帧尝试重分支。超时和积压原样记录 | 事件调度成本与正常场景干扰 |
| H | F 去核心创新，沿用 E 对应处理，其余配置不变 | 核心机制的消融；与 E 不同的普通集成变化单列 |

在 E/F 之外，增加相同封存候选集的配对排名对照，同点数或同观测池，并用体素空间配额匹配随机。比较普通单候选显著性、原生奖励、固定最大与平均奖励、双侧支持与几何差异。若使用同预算全云多初值作额外基线，单独统计在线优化次数。M0D0 等组合可用描述性交互，因子不等同则不声明因果。

## 外部完整系统

- 选 HDL Localization 作为原生固定图 LIDAR+IMU 外部基线。上游全局图、原生多线程 NDT、IMU 预测与固定图更新具备公开实现。优先固定上游提交和 ROS Noetic 构建，再统一话题和输入。P64 Q2 用已归档 PoseEstimator，其配置与默认上游存在区别。若与 A 保持相同上游主链，则同一结果只能计一次主要独立基线。 [上游](https://github.com/koide3/hdl_localization)
- 选 FAST-LIO Localization 作为异质外部基线。现有 Noetic 叉 7fae5d1f9c0d9f6a64c6ac936f2239b9ee9cb18d 的 scripts/global_localization.py L64–72 做多尺度 ICP、L110–144 裁剪先验视场，前端为 FAST-LIO 里程计，transform_fusion.py 输出地图校正下的连续位姿。该组合从同一原始数据和同一先验图验证，动态局部里程计地图不视为测试建先验图。禁用采用未来参考初始化的配置。 [上游原定位项目](https://github.com/HViktorTsoi/FAST_LIO_LOCALIZATION) · [Noetic 版本](https://github.com/davidakhihiero/FAST_LIO_LOCALIZATION-ROS-NOETIC)
- Koide 等 ICRA 2024 固定图紧耦合系统列为文献参照。未核实可复现相同完整实现和输入口径前，不加入数值主对照，也不把相近仓库标为原版。 [作者原文](https://arxiv.org/abs/2402.05540)

## 指标口径与冻结

位姿在已验收地图坐标系的同源时标上一一关联，以独立地图参考外参完成坐标转换。固定图主结果不做测试轨迹整体自由对齐。ATE（绝对轨迹误差）RMSE 用同帧位置差均方根，另报告 SO(3) 旋转角误差、P95 与最大误差；RPE（相对位姿误差）使用固定 1 s 与 5 s 间隔的相对 SE(3) 误差并列出样本数。超时缺帧或失锁须计入覆盖和失锁持续时间。报告共同有效区间的精度与完整覆盖两张表。

正确候选或单次错误匹配使用 0.15 m/2° 与多尺度阈值，失锁预注册连续帧/持续时间界限，在同一测次使用固定定义。正常/退化/重复结构的离线区段标签从独立资料冻结。评估候选可达、错误接纳及拒绝、恢复率；正常区段报告风险与覆盖。Mean/P95/Max 单帧延迟端到端从接收至提交，细分 CPU、峰值常驻内存、事件触发比例、排队、丢帧及处理实际频率。10 Hz 工程资格须在目标 Jetson 连续窗口跟上输入并控制延迟积压。跨机器不得直接比较秒数。

提出的首轮保守系统门槛是 0 重复提交，正常帧不开几何重分支且结果对齐同后端 A。候选资格保持此前 90% 正式 R2 目标，实际事件不足时只报告分子分母。F 相对 E 的条件必须在看持出前冻结，要求退化区错误匹配率和累计失锁时间改善，正常区覆盖与误差不劣，并由 H 消融解释增益。置信区间使用独立试次/区段配对重采样。
