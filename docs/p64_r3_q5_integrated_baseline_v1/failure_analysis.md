# 失败复核与限制

原始 M3C2 对核心点输出为子集。第一版按一对一输出计数拒绝；修复后使用输出坐标还原源点号并维持 UNKNOWN（证据不足），再跑全部对照。最终真实候选视图仍无满足两侧样本门槛的点，不能将失败归结为初版解析错误；建议先用同物理面做有标注的密度及投影资格验证。

W2 主动第一帧即出现拒绝。冻结策略在无足够差异支持和缺少候选时，只允许创新和关联均过门的原生观测。早期预算用完后，这个策略仍可重复拒绝，产生实际状态轨迹退化。正常 30 帧不受影响无法涵盖此风险。狗窗因缺独立参考，只能把 39/50 次拒绝作为可追溯的工程结果。先验证连续拒绝与协方差演化，再做新的候选公式试验。独立正常对照、历史代理和真值受控的公开序列须分开计数。

需补采时使用一趟独立建图和至少两趟不同起点、速度、方向的查询。在近似门框走廊留 20–30 m 重复结构段和两端非重复锚点，包含进、出及静止。查询中参考采用经时间同步的光学跟踪或独立全站仪测量，仅离线读取。先核对主题及时间同步，再使用当前 Livox 主题录包，例如 `rosbag record -O /home/jian/rosbag/dog/p64_corridor_query_01.bag /livox/lidar /livox/imu /tf /tf_static`。参考独立写盘并保留坐标变换和校准记录。
