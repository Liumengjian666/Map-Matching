# Q5 预运行协议

Omni PIE: 独立 Diff 先验及 Q2 30 帧原始传感短窗，Q3 W2 72 帧为挑战窗口，同一已封存初值及输入。Q2 里 B25 为弱竞争且历史支持不足，Q3 W2 也只有弱竞争。参考轨迹仅在因果迭代和日志完结后读取。A 直接运行归档 HDL PoseEstimator，OFF 使用同代码的空决策钩；比较两次输出的时间、迭代/关联、位姿元素绝对误差≤1e-6。真实状态为 16 维 UKF，记录完整前/后协方差和提交时标。实验 C/B/E 分别启用候选、退化诊断和合格组合，D 需独立合格；统一图/后端。

原有网格 S0 范围 x/y±2 m、偏航±5°，0.2 m、1°，4851 固定姿态。S3 原封存双中心复用。每窗搜索最多三次，拟合每触发最多两候选启动和最多一次被选候选全云精修。普通 NDT 拟合的事后否决检查 0.25 m/2°，不得声称有界求解。工作站影子预算每触发 25 s；外部几何子进程 ≤4 s；候选拟合开始前检查剩余耗时，完成后检查是否超时。运行平台实时性另评。

自然触发为弱方向特征值比 <0.01、关联<0.75、无有效迭代/无收敛、相对 IMU 预测 >0.20 m 或 >4°。只实验确定性短窗。正常窗 25 及 W2 32 是预先指定的强制触发，记录为接线验证而非自然检测准确率。另记录局部诊断与候选探测的不同原因。测试短预算开关会显式注入资源不足。候选有效关联≥50%，原生有效迭代且关联系统正常时可接受原生回退，关联≥75%且相对 IMU ≤0.35 m/6°；否则仅传播。几何主动通过预计需≥64双侧差异点、至少5个空间块、原生全点排名同首选、空间两个半区均支持首选，且首选相对原生不位于边界。回退和选择规则仅属工程护栏。影子状态一律走 A。几何前置用 CloudCompare 原始 M3C2 验证，先跑真实来源表面和诊断干预。DeCOD 若不能通过真实重复/视图资格，只运行细粒度核心诊断，保持组合关闭。

机器狗工程附加验证冻结为历史原生日志 5949–5998 帧（围绕预先已有曲率研究的 5979），从以往日志 5948 的先前原生通过姿态完整四元数初始化。使用独立日期建图资产、同 bag 实际 LiDAR/IMU；无外部真值或代理参与状态。与历史机器狗的 PCL/EKF 有后端区别，结果只作 V1 工程诊断；强制触发选索引 30。
