# 细粒度匹配实现

decod.py 固定一份重力对齐矩形参考轮廓，按归一化弧长与 0.30 m 轴向格生成偏移场。候选共享轮廓及坐标基准，计算高斯加权局部块的唯一双向最近邻，并记录真实对应坐标。原文未公开的搜索支持与一致性参数已冻结。输出原始场、拟合偏差、补偿场以及独立原生排名。

Mode A 在 W2 使用单一原生姿态与因果局部点集，网格搜索次数为零。方向性固定匹配另使用物理弱轴，实际执行 A5、A6 两个排序及 A7。Mode B 用封存候选和已有候选搜索。E2 独立运行，E3 另测 M3C2 共享掩码接口。候选比较中的名义轴向位移由两个横断面地标原点的差给出，其他维度保留候选姿态。未通过形状与唯一关联时，该位移只记录为诊断。

axial_probe.py 用单个轴向位置残差给出单位权重雅可比，同一地标支持块不重复累计为独立信息。没有经确认的实际补充状态观测。
