# Q6 方向性补充协议

固定 W2_32（独立 Mid-360 参考）和机器狗 30（旋转去畸变、无独立真值）作局部匹配。局部扰动为历史因果 NDT 起点沿物理体素法向场最弱轴 +0.30 m，不读取参考。B25 使用已封存的分离候选作另一项非局部压力对照。一次执行每个配额和方法，随机种子固定 6406。硬删除配额 20/50/80%，50%作主对照。统一旋转等效长度 5 m。弱轴有限差分 ±1 cm 等效位移，另外跟踪 DIRECT7 关联集合变化。

C0 法向点面约束，C1 原生每高斯奖励乘逆协方差的 PSD 代理，C2 原生奖励中央差分，梯度同时按固定关联公式计算。以因果局部位置的物理体素法向场决定轴向；另报告原生 PSD 谱和绝对/比例法向信息。物理场法向 0.50 m 原始体素，直接沿 LF-GICP v2 的非正则化法向公式。梯度与信息不能等同。

D0 全点；D1 随机；D2 等点数空间轮转体素；D3 点面弱轴选点；D5 Gelfand 六分量最弱累计轮转；A2 用 EAMC 六维乘积启发式对照，清楚标明与离线地图压缩的区别。A4/D4 固定种子上的 LF-GICP 式均值归一方向权重，以 4N 条同点重采样实现冻结整数权重下真实 NDT 目标，重采样误差与运行量一并留档。无需改动原生源文件，奖励、梯度、Hessian 与线搜索均在同一固定重复点集上。对照不尝试未授权更改连续后端。

P1 在单帧先选点后构造 DeCOD 描述。P2 保留原始描述提取与误差补偿，构造共享查询图表的空间格遮罩后匹配，任一实验因证据不足均输出原生回退。成熟模块的两种直接组合至少运行局部匹配调用；有明确可匹配结果才追加整云原生精修及状态使用。
