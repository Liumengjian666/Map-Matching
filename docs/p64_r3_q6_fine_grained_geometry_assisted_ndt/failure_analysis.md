# 失败与未验证范围

- 既有 NDT 弱谱门在三个原输入短窗没有满足阈值的自然强退化事件。W2 的单帧 +0.30 m 为预定应力测试，B25 为归档分离次优模式，两者分开统计。现场狗的固定方向实验只能作工程诊断。
- 20 帧高覆盖没有建立符合原文的通道轮廓。不同位置低相似也受可见范围影响，仍缺已认定的相似门框对及独立真实走廊测试。
- 机器狗 50/50 使用现成 Livox 旋转去畸变，头时刻与点 timebase 最大差 222 ns，尾端 IMU 括号最大 3.546 ms。按既有同名雷达坐标的旋转约定处理。缺经核验因果速度，未补偿扫描内平移。另有约 761 MB 高密图但属于不同建图版本，冻结原生图保持，未混用。
- A6/A7 无可替代位姿。实际几何输出与完整定位性能须分别报告。机载实时与 ROS1 新部署未实施。
