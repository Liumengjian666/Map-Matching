# Q6 冻结协议

以 Q5 远端 558a768 为起点。冻结原生地图、NDT 目标、HDL UKF、搜索预算、初始化和三段真实输入。工程回归 FIXED 诊断全开、增强位姿不提交，绝对矩阵与协方差最大差 <= 1e-6。旧组合引用冻结 Q5 ACTIVE。非有限输入仍隔离。不同排名并行记录。

几何资格采用固定 1、5、20 帧递增因果窗口（使用过去原生定位位姿，显式区分帧刚性拼接与逐点去畸变）。原论文的 20 扫描、5.5 cm 体素、轴向 DoG 2.5/10 cm、0.8 m NMS，描述 16×256、0.30 m/格、半径 2.4 m。地图使用独立几何采样；禁止候选依真值重排序及候选独立拟合全部位姿。发布对照含原始、基础和补偿结果。几何目标只在有限候选或冻结的局部轴向范围求值。参考仅在封存后用于评价。固定的 Hard 历史帧只作开发回归。机器狗的厘米级证据须有逐点同步、外参及去畸变，缺项应明确区分工程输入与算法验证。
