# 基础轮廓失败与有限适配

冻结地图保留。真实点云用因果历史姿态聚合。W2 的一份局部地图约在独立 Diff 重建图中，机器狗输入采用 Q6 旋转去畸变短窗，扫描内平移仍未认证。没有用另一次狗地图重建替换现有几何。

## 三项可测因素

1. **空间范围。** W2 矩形的全源子图贴合率 21.9%，匹配地标在共同半径和轴向范围内为 29.4%，图侧 27.8%。范围不一致只能解释其中一部分。相同裁剪还把 W2 查询奇异值比从全范围 2.089 降至 1.030，说明远点使旧流程高估局部狭长性。图侧仅 1.137。
2. **通道轴与物理弱方向。** W2 固定先验轮廓轴在世界约 (0.657,−0.754,0)，物理体素法向弱轴约 (0.996,−0.027,−0.081)。二者不能互换。实际局部地图包含多断面、侧方开口和远处回波，图中的横截面有多团簇分布。未做房间、门框、噪声的逐点语义标注，轮廓外观察仍是有效几何。
3. **重力。** W1/W2/W3 的短时 IMU 比力方向和地图 Z 夹角约 0.29°/1.16°/0.41°。狗窗约 26.30°。既有原包启动前约静止 200 个 IMU 样本相对机身 Z 夹角约 33.88°，提供安装方向佐证。运行中比力含动态加速度，不能把两值当作同一帧标定。C2 的 IMU 诊断把狗窗口贴合从 9.74% 提至 12.49%，仍未形成可靠对应。

## 四类模型

- C0：保留 Q6 分位数矩形。W2 的 D-original 有 5 个内点，仍未达轮廓、延展和内点门。
- C1：按规则截面适用场景只拟合一个共同圆。合成圆柱径向环带控制通过。真实 W2 贴合约 6.0%，不适合圆模型。
- C2：采用重力约束的分段墙面/地面/天花板平面，独立拟合有限横截面位置，自由度不吸收轴向位移。W2 约 15.6% 贴合，6 对内点。没有通过原始 90%。
- C3：在 C2 上只比较实际共同观察格，并保留可比较格和关键点分母。W2 分数 0.60 来自 **3 对**内点及小分母，轴向残差相对封存扰动达到 0.47 m。共同可见局部方法目前仅有诊断定义，实际数据不足以认证独立资格。没有放宽阈值来提高接受数。
