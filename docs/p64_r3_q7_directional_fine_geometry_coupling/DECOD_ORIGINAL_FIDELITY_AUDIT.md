# DeCOD 原文对应核查

Q6 把 3×9 误称为论文未公布的描述块尺寸。原文 IV-A.3 明确给出 9×33。Q7 保留 Q6 3×9 的重运行对照，另以 9×33、原文几何资格和地面遮罩做 D-original 重实现对照。两组在同源、同一候选空间下运行。没有覆盖 Q6。

| 原文机制 | 核查与实现 |
|---|---|
| IV-A.2，通道延展 | “two largest singular values”按去中心化点坐标矩阵解释。σ₁/σ₂≥2 等价于同一数据的协方差特征值比≥4。Q6 用特征值比≥2，会放过奇异值比约1.414–2的样本。Q7 同时报告两个量 |
| III-A，有效描述格 | 16×256，轴向±2.4 m、0.30 m/格，周向归一弧长。格内取有符号法向偏移均值，空格保持缺测 |
| III-B，拟合偏差 | 局部观测中最小二乘拟合 α(p)+γ(z)+z(β₁n₁+β₂n₂)。论文描述高斯加权、相互观察支持。数值高斯带宽和最低共同格数未列出，本研究明确固定近似值 |
| IV-A.2，底部遮罩 | D-original 使用重力横截面相对下方±30°遮罩。D-adapted 复用 Q6 无该遮罩设置 |
| IV-A.2，轮廓适用性 | 原文的 90% 投影点距轮廓 0.18 m 条件保留。D-original 核查查询与图两侧。在冻结的空间范围内独立于偏移筛选点。全扫贴合率另列，绝不通过丢弃轮廓外点抬高分母结果 |
| III-B/III-C，匹配 | 正向、反向分别计算共同观察块距离，执行唯一双向近邻和一致偏移校验。报告 9、15 两档。局部索引窗、描述相似阈值和位置一致阈值是显式适配。正反方向均可诊断，固定先验姿态直接更新仅接受与当前姿态约定一致的正向 |
| III-C，式(3)–(4) | 将两侧横断面形心统一到第一坐标系，位置误差 tᵢⱼ−(cᵢ−cⱼ)，轴误差 1−(aᵢᵀaⱼ)²。若 cⱼ、aⱼ仍在第二帧，须先乘 Rᵢⱼ。因子提供位置与轴对齐，轴向滚动角自由。原文把该因子与里程计合并并用 Huber 损失。Q7 只验证横断面位置的轴向投影位移及局部固定图接口 |
| IV-A.4，实验任务 | 原文在无共享扫描、时间分离的去返程间寻找回环。Q7 在独立固定先验图与当前因果子图之间配准。没有可核实的本地 GEODE Shield/Tunneling 原始场景，圆柱控制为明确合成几何 |

论文原始尺寸已纠正。D-original 是原文核心的纸面重实现对照，官方回环完整流程、作者未公开的实现细节、数据域条件和完整位姿图优化仍有差异。 [DeCOD 原文](https://arxiv.org/html/2609.36753v1)
