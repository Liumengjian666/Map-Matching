# 方向性选点与细粒度几何的组合边界

1. **空间采样足以解释部分单帧收益。** W2 +0.30 m 的单弱轴选点弱向误差为 1.97 mm，同空间配额随机为 2.69 mm。后者总平移误差 14.27 mm，略低于前者的 14.67 mm。跨 W1/W2/W3 十二个种子，弱向均方根误差依次为单轴 32.29 mm、空间配额随机 28.17 mm、普通体素 24.21 mm。配对表现无法确认弱轴排序具有额外泛化收益。
2. **强约束需要同时评价。** 三窗压力连续运行弱向均方根均小幅下降，并伴随小幅强向误差增加。W1/W2 的恢复时间未改善，W3 提前约 0.10 s。三个窗口间传感方向不同，W1/W3 物理弱轴明显有竖直成分。当前不能合并为同类走廊纵向失锁事件。
3. **自然触发的检测器分歧。** 狗短窗的原生 NDT 谱和 LF-GICP 法向场迁移未触发。点面的 X-ICP 和 DCReg 在抽样 8/8 帧识别平移部分定位/退化。补做的在线 DCReg 默认平移判据在 49/50 帧触发，触发轴与物理法向弱轴的绝对点积中位数为 0.9993。其轨迹与 A 最大相差 1.181 m。缺少该时间段独立参考，不能判明影响的正负。
4. **共享点会改变细粒度支撑。** W2 的 E2/E3/E4/E5 分别产生 6/3/4/5 对内点。E3（先选点）实际把 102,276 点的子图变为 33,335 点，后遮罩对照从相同完整图生成描述。E5 保持完整描述，与 5,508 点的方向 NDT 分开。两路数据同一帧和坐标，E6 只有合格几何位置约束时才投影到弱方向。无合格实测，E3–E6 的返回位姿仅来自方向 NDT，不能比较几何增益或宣称已找到最终融合负交互。
5. **检测率和误差检验不能替代。** 合成圆柱在已知两种方向位移下通过位置关联；室内候选在同形式的测试中失败。真实最高分可能来自小分母，需报告分子、分母、空间覆盖与位姿误差。
6. **B25 与局部弱轴分开。** B25 已归档种子沿所选轴误差约 1.93 mm，正交误差约 1.702 m。当前重跑的 Gelfand 六向均衡可把总误差从 1.678 m 降至 0.095 m。单弱轴结构遗留约 1.707 m。该事件支持非局部模式分析，不能用来解释局部方向估计无效。
