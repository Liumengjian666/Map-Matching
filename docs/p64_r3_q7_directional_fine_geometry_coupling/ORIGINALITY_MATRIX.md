# 机制查重与候选切入点

| 问题 | 与现有机制重合 | Q7 决策 |
|---|---|---|
| 根据方向贡献选择和保留点 | Gelfand §3 六方向累计，LF-GICP v2 式(7) 弱向 Fisher 加权，Q6 已运行两类核心 | 基础选点及权重无原创结论 |
| 由欠约束坐标驱动互补观测 | COIN-LIO §III-E 将弱平移方向投影到强度图像选择互补梯度。方向与观测耦合已知 | 需要证明固定先验图的几何提供原生 NDT 缺少且可复现的物理观测 |
| 显式细粒度轮廓补充轴向位移 | DeCOD III-C 已通过横断面位置因子约束纵向 | 本轮只证明合成控制与室内表示失败存在差别 |
| 全点描述、子集 NDT 并行组织 | 方向选点和地标描述皆是成熟模块，保留不同点集是明确直接组合 | E5/E6 无可提交观测，无法确认性能增益。先研究共享空间的物理可观测支持 |
| 强弱位姿协同 | 方向约束、事后保模式、同帧单次提交已有实践 | 只有稳定地标合格且简单接口在同协议下失效后再考虑新机制 |

当前优先验证两件事：局部重力与真实横截面的坐标兼容，以及不损害描述邻域支持的方向选择接口。正态分布变换（NDT）、点面采样、偏移描述和无迹卡尔曼滤波（UKF）的组合本身不建立原创性。 [Gelfand](https://aperture.stanford.edu/papers/stabicp/stabicp.pdf) · [COIN-LIO](https://arxiv.org/html/2310.01235) · [LF-GICP](https://arxiv.org/html/2608.19522v2) · [DeCOD](https://arxiv.org/html/2609.36753v1)
