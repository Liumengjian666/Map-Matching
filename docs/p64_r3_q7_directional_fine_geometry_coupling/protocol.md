# Q7 冻结协议

基准 28966a1。固定四个由旧实验资产定义的区域：Nav A W1/W2/W3 第32帧，狗旋转去畸变窗第30帧。Nav 地图与查询独立，测试参考不进入算法。前三段分别按原资产的轨迹时间和空间分开。机器狗仅工程诊断。Q6 固定 B25 次优候选作为 Mode B，和受控弱轴 Mode A 分开。

Mode A 使用固定世界物理法向场弱轴，沿 ±0.10、±0.30 m 从历史因果 NDT 姿态扰动。所有方法使用相同源和地图，原生目标保持。主预算固定 50%，W2 +0.30 m 追加 20/80%。随机种子 6407。等空间配额按雷达坐标0.50 m立方体和方向选点分配。三类贡献定义分别输出。Q6 的原生谱 <0.01 门限不改。持续事件以相邻时标测量。无探测事件不是退化不存在的证明。原版 LF-GICP 门槛在核查源码后使用，作者时间门未运行时仅报告单帧证据。

连续用现有各72帧的 W1/W2/W3，分别有 A/B +0.30 m 同锚扰动。B 的前四帧是预先指定压力触发，其余仅真实原生谱触发。W2另跑无扰动 A/B，比较自然触发及逐帧原生回退。正常路径不做方向性重匹配。单次地图观测，替代失败时保留有限原生位姿。除以姿态质量及求解收敛的数值条件外不新增拒绝准则。

细粒度：D-adapted 复用现有3×9对照，D-original 核对9×33、中心点矩阵奇异值比、地面扇区遮罩并保留90%贴合，分别报告≥9和≥15内点。两者是源码可追溯的重实现对照，结合统一室内图，不叫全原版复现。圆形/矩形/稳健面拟合/共同可见局部描述使用冻结参数。先用已知位移的圆柱控制，再跑真实W1/W2/W3及一个狗工程窗。用同一坐标和物理时刻做E0–E6；无合格地标时保留原生或单模块结果，不把回退当作组合效果。仅在固定候选和实际短窗中运行，不开展大规模下载。
