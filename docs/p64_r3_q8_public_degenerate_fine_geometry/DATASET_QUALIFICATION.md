# 地图、真值与坐标合同

GEODE G1–G3 为 C 级自然退化诊断。三个窗口按传感器索引冻结。各用前 24 帧增量点面 ICP（迭代最近点）建局部先验。第一帧根据可用 IMU 对齐重力，最后地图帧作为原生 UKF（无迹卡尔曼滤波）初值。后 36 帧与建图互斥。板载 IMU 和 Avia 均带 livox_frame 标签，按同系输入适配，未使用 Xsens。Leica MS60 棱镜文件仅三维位置有效。作者 Gamma 评价脚本含杆臂，但当前三个局部地图没有同 Leica 闭合外部坐标。只比较各自相对首帧的位移模长，保留杆臂与时间误差限制。[官方工具](https://github.com/PengYu-Team/GEODE_dataset/tree/c6e930623d4fed450d7fc50e16e3ffe0288b692b)

IILABS W1–W3 为有 A 级资产合同的参考窗口。三窗均是已曝光样本，未达到自然退化门槛。Diff 图与 Omni 查询独立，继承 Q3 参考独立初始化。OptiTrack 世界系参考使用 Q1 的固定平移和 0.4612 m 杆臂插值。正式参考只在主输出封存后读入。GEODE 位移模长的中途检查是在样本、原生运行与主匹配程序固定之后，未用于修改参数和选择样本。
