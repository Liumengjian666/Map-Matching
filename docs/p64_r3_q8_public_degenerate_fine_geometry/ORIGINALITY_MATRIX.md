# 机制重合与研究缺口

| 方法 | 已有机制 | Q8 结果 |
| --- | --- | --- |
| Gelfand | 点面谱驱动的稳定采样 | 单弱轴在等点数和同优化次数下未胜过体素。 |
| LF-GICP | 物理法向场、信息稀释和退化触发加权 | 迁移检测在 GEODE 与 NDT 谱分歧。该核心机制已有先例。 |
| COIN-LIO | 几何弱向驱动的互补强度观测 | 弱向互补早已有之。本轮只测点面物理偏移。 |
| DeCOD | 通道基底分离、轴周向匹配及正交位移因子 | 单独提供轴向微结构位移已有方法。同录包的短图定位适配未过原资格。 |
| EAMC | 多姿态贡献和空间覆盖压缩 | 按方向敏感度排序、空间约束均已有先例。 |
| X-ICP、DCReg | 分方向可定位性、强弱方向解耦与部分约束 | 检测及约束数学已有成熟来源。 |

首要待检验问题是独立、等分辨率、已运动补偿的地图条件下，较稳定的局部面片位移是否能在方向性 NDT 之后继续改善。IILABS 三个参考对照中，方向性组合弱于局部面片单独处理。真实困难区段仍欠缺合格的绝对定位证据。当前无法据此确认原创协同机制。
