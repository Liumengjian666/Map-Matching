# 真实结构及重复证据

[实测隧道投影](visuals/tunnel_geometry.png) 叠加真实先验、查询、按弱向敏感度排序的保留/删除和物理法向场最弱轴。在示例 [G1 的高贡献查询点](visuals/G1_fine_scan.pcd) 与 [对应图点](visuals/G1_fine_map_correspondences.pcd) 中，使用点面法向敏感度和空间支撑定位局部横切小面。没有册录确认这些小面对应哪一条接缝或凸起。图与查询为不同帧。候选面片需在两个互不重叠的建图半窗拿到近邻支持。仍共同依赖同一估计坐标及运动畸变。

三处盾构区域得到 35、21、13 个高弱向近邻候选，残差中位 28.4、24.7、29.2 mm（欧氏近邻距离）。仅 G1 通过预设 30 点加四空间块的局部拟合条件，结果修正 0 cm，缺共同参考坐标。完整的高分辨率点面方案三窗都输出局部解，修正为 −1、0、0 cm。它们远不足以解释实际端点位移短缺 4.39–5.31 m。在 IILABS 有跨测次图/查询几何支撑且可评价局部修正，未确认其为自然退化救援或人工标定的同名物理地标。六窗 [细粒度代价曲线](visuals/fine_axis_costs.png) 和 [实际面片](PHYSICAL_LANDMARK_REPEATABILITY.csv) 提供基础测量。
