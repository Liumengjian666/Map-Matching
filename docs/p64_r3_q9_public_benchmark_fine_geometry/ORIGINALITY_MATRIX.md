# 机制重合及本轮证据

| 源 | 成熟机制 | 本轮证据 |
| --- | --- | --- |
| Gelfand、LF-GICP | 稳定性选点、物理退化方向、观测加权 | 同空间配额随机可达到同弱轴结果。当前未证明方向打分独立收益。 |
| COIN-LIO、DeCOD | 补充弱向观测、局部通道结构相对位移 | Q9 使用常规空间点面对应和轴向位移。DeCOD/ M3C2 保持历史冻结。 |
| X-ICP、DCReg | 方向条件与补空间保护 | R2/R3 及方向投影只用于机制分析。亚厘米探针表明一厘米搜索网格也是混杂因素。 |
| 常规 ICP 稳定对应 | 固定对应残差重算、重关联及重复观测 | P3 在主网格中恢复部分收益，没有形成独立困难场景的因果证据。目标点改变也可能仍在同一物理平面。 |

Q9 的贡献是逐项分离组合变量。方向性、局部目标尺度、重新关联和网格量化仍需在自然退化的闭合坐标基准中复验。当前不提出协同创新机制。
