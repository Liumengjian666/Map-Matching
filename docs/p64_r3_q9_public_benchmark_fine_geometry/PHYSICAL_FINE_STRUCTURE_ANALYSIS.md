# 面片物理归属

IILABS 的高分辨率输入来源于独立 Diff 地图和 Omni 查询。0.055 m 点池先在 T0 上找到近邻，再按粗糙度、法向弱轴敏感度与 0.25 m 支撑格筛选。导出的点号和目标身份在同一世界系下固定。W2 的匹配面片、候选重关联点、原查询对应和局部先验均提供 PCD。

三个配对帧共包含 74、167、68 个至少四个观测的 0.50 m 空间格。格内对应集最大轴向跨度的中位数 0.220、0.223、0.225 m。目标法向的 k=20 邻域主要切向 RMS（均方根）尺度中位约 0.047–0.048 m。这些是支撑尺度，与凸起/凹槽的高差不同。选点分布说明短小的平面、墙体倾斜或门侧类几何都有物理候选，当前没有逐区域独立地标标注可以确认接缝或厘米结构身份。普通平面、噪声和错误关联均未从这次匹配中得到可靠语义分离。

严格同点数空间对照给出直接边界。F3/F5 在 W1、W2、W3 各共享 526/815、1409/1918、484/761 个源点，集合并不相同，三个 1 cm 网格终值却相同。因此这轮证据最多支持空间配额和有用的面片观测，不能把改善归因于真实厘米凸起或逐点方向排序。普通体素 F4 的空间分配不同，不能用于隔离逐点排序本身。

Corridor01 地图、查询和重建可用于确认真实物理场景。正式稳定微小结构重复性与位置收益需要可靠闭合参考。未将地图近邻命中当作同名地标基准。
