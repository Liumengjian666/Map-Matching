# 实验失败及归因边界

1. Corridor02 的配额由确认下载后的服务响应明确显示。Corridor01 的同类确认 URL 有效。文件存在与公开可传输是不同事实。Corridor02 的地图—参考姿态关系也仍需作者说明。
2. Corridor01 已验证可读取真实 Velodyne 与 IMU（惯性测量单元）。地图和静态资产哈希匹配历史值。公开初始化矩阵和轨迹之间的空间语义及注释时间在作者接口中未闭合，暂不能形成正式绝对误差或自然严重退化救援对照。保留短窗几何诊断与传输证据。
3. 配对在 1 cm 网格重现 Q8。P0 为 14.59 mm，P1 为 20.36 mm，P2 为 17.78 mm。P3 保持旧对应并重新计算残差得到 16.53 mm，P4 为 17.17 mm。W2 的 P1 同时入选的 1629 点中仅 655 个仍对应同一地图点，法向变化中位 1.88°。小角差不能说明目标点来自不同物理面。残差 5 cm 门下的计数只作为几何一致性。
4. 强补空间本身会被二次 NDT 改变。仅保留强补空间变化 R3 时，强平移误差由 57.25 增至 60.21 mm，1 cm 网格的弱向误差为 14.59 mm。R2 只保留弱向变化，强误差回到 57.25 mm，弱误差却为 20.36 mm。加入同残差的亚厘米局部探针后，R0/R1/R2/R3 为 18.12/17.51/18.49/17.19 mm。原 1 cm 弱轴排序对网格量化敏感，不能认定强误差是弱轴恶化的主因。P1 优于 P0 的亚厘米结果也不支持其整体三维更优。
5. 同源点池、同局部范围、相同 NDT 高斯体素下，高分辨率输入地图未自动提高弱轴性能。F1 是 26.54 mm，匹配低分辨率的 F0 为 19.83 mm。点面方向 F3 和等空间配额随机 F5 同为 14.59 mm。足以控制空间配额后，逐点方向排序没有额外正证据。
6. 实际组件计时显示面片在本实现需要约 2–3 s 的冷态法向缓存，统一 1 s 增量预算下所有面片臂超限。表中回退按实测分量实现的离线判断，不是强制终止的在线计时。持久热缓存或等端到端吞吐未验证。
