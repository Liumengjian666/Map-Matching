# Scoped line-ending regression

The first staged `git diff --cached --check` stopped before commit on the eight
new header-only visual/unreached-evaluation CSVs: Python's default CSV writer used
CRLF, which this repository flags as trailing whitespace.

The writer now explicitly uses LF. Only those eight newly generated header-only
files were mechanically normalized; no scientific CSV or frozen receipt changed.
The header fixture checks that generated bytes contain no CR. Complete hashes are
regenerated and staged-diff checking must pass before commit. No Git whitespace
setting or research gate was relaxed. No NDT or visual computation was repeated.
