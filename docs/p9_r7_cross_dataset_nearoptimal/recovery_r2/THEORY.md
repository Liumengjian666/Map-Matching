# R7-R2 historical adapter/storage recovery

This task resolves prerequisites, not the R7 ambiguity-evidence hypothesis.
Storage authorization and historical source provenance are independent gates.
Actual write/read success under the current unrestricted session closes only
storage. Wrapper equality does not close its transitive implementation.

An exact historical source chain would require source/include/configuration,
launch, calibration, runtime arguments, generator command, hash algorithm and
Velodyne version. Re-deriving a plausible rotation-only branch from today's
full-SE3 implementation cannot substitute for recovered historical provenance.

After one bounded unsuccessful history/backup check, stop v1 reconstruction.
The authorized result is HISTORICAL_V1_LINEAGE_UNRECOVERABLE_IN_AVAILABLE_SOURCES,
qualified to the listed inspected sources. The unique NEXT is
PROSPECTIVE_P9_SCAN_END_INPUT_PROTOCOL. That next contract needs a new input
version and decision-AI approval; it is not implemented or run in this task.

No NDT parameters, R6 gamma, budgets, oracle definitions, GT initialization,
map, frontend, fusion or candidate selection change. One-shot reconstruction
and both baseline replay budgets remain unconsumed.
