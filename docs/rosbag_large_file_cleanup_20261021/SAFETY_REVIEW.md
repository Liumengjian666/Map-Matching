# 删除安全审查与限制

删除前本地独立审查提出：哈希/状态分离绑定、不可逆删除先于日志、最后检查不足、祖先挂载遗漏及失败路径测试不足。已采取：同一次描述符读取绑定SHA和起始签名，删除前再对目标完整重算SHA、重验保留副本，所有文件版本签名一致才继续；持久INTENT先于unlink，UNLINKED先于目录fsync；祖先挂载/符号链接/设备/目录fd路径和最后文件签名复核；补充失败测试。

首版扩展测试因Python3.8的Path.parents不支持切片而失败：16项中9项报TypeError（slice与int比较）。这是删除前发现的测试失败；尚未删除真实文件。改为先转list再切片，保留本记录，不把首版写成通过。

普通文件unlink不是跨文件事务：flock仅约束合作进程，fuser/lsof是时点检查，不能排除恶意或非合作写入者在最后指令间隙修改文件。执行前要求目标及保留源均无其他进程占用，两次进程检查、版本复核和最后目录fd检查；发现任何并发、签名变化、权限/扫描警告或I/O错误即停止。不得声称能防御任意并发对手。整个操作不修改/锁定生产Git索引或原始源内容。

如果中断，INTENT与UNLINKED日志用于核对真实路径状态；不自动再次执行同一次删除任务，不隐瞒部分删除。删除只涉及明确列出的完整内容重复副本，不依靠可重建性猜测清理唯一结果。
