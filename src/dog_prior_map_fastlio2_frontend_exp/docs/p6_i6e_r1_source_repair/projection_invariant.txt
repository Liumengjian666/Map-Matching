P6-I6E-R1 directional projection invariant results
====================================================

Test source: scripts/p6_i6e_conditional_compensation_test.cpp
Inputs include nonzero LiDAR-IMU lever arm, non-identity IMU attitude, length_scale_m=0.8, mixed rotation/translation weak direction, and non-orthogonal physical coordinate map A.

Single weak direction:
  reliable_rank = 5
  ||B^T B - I||_F = 1.14465e-16
  ||B^T A Uw|| / (1 + ||A Uw||) = 1.79954e-17
  ||B^T r1 - B^T (r1 + A Uw * 0.1)|| = 3.98609e-17

Two weak directions:
  reliable_rank = 4
  ||B^T A Uw|| / (1 + ||A Uw||) = 5.46858e-17
  ||B^T B - I||_F = 2.9962e-16

These pass the specified 1e-9 leakage bound. The test exercises the built matrix projection, not a GT-derived quantity.
